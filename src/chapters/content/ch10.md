In the directed case, an arrow and its reverse were two separate moves. Now let each link work both ways and ask how few links can keep the whole graph connected. A tree gives that minimum. The way we build one will also give us two different search procedures.

## 10.1 Simple Graphs and Standard Families

For a simple graph an edge joins two distinct vertices and has no direction. Using relations, this means $E=E^\top$ and $E\cap \operatorname{Id}_V=\varnothing$. Using unordered pairs, the same graph has $E\subseteq\binom V2$. We will count **one** edge $\{u,v\}$, even though the matrix and relation record two entries. An undirected cycle must use distinct edges, so going out and back along a single edge does not make a cycle.

The neighbourhood $\Gamma(v)$ is the set of vertices joined to $v$, and the degree is $\deg(v)=|\Gamma(v)|$. A $k$-regular graph has degree $k$ at every vertex. When learning a family, read the rule for one neighbour before trying to remember the number of edges.

| Graph | Edge rule | Vertices | Edges |
| --- | --- | --- | --- |
| $K_n$ | Every pair of distinct vertices | $n$ | $\binom n2$ |
| $P_n$ | Consecutive labels in $[n]$ | $n$ | $n-1$ |
| $C_n$, $n\ge3$ | Consecutive labels, including the last and first | $n$ | $n$ |
| $K_{m,n}$ | Every pair across the two parts | $m+n$ | $mn$ |
| $M_{m,n}$ | In the grid $[m]\times[n]$, one coordinate changes by 1 | $mn$ | $(m-1)n+m(n-1)$ |
| $Q_d$ | In $\{0,1\}^d$, exactly one bit changes | $2^d$ | $d\,2^{d-1}$ for $d\ge1$ |

A grid is $P_m\square P_n$. Count vertical and horizontal edges separately. The hypercube $Q_{d+1}$ consists of two copies of $Q_d$, joined by matching the equal suffixes in the two copies. This is $P_2\square Q_d$. Each vertex has $d$ neighbours in $Q_d$, one per bit. Every edge has two endpoints, giving the table count. In $Q_0$ the only vertex is the empty word $\varepsilon$ and there are no edges. The distance in $Q_d$ is the number of positions where the words differ. Every differing position has to change at least once, and flipping just those positions attains that lower bound.

::: practice Find the boundary vertices
Find the degree sequence of the $2$ by $3$ grid, and the distance from $(1,1)$ to $(2,3)$.
::: answer
The four corner vertices have degree 2 and the two middle vertices degree 3. The degree sequence is $(2,2,2,2,3,3)$. To reach the target requires one row move and two column moves, and those moves can be done consecutively, so the distance is 3.
:::

## 10.2 Trees, Roots, and Spanning Trees

A tree is a connected acyclic simple graph. Connectedness gives us a simple path between any two vertices. Now suppose we have two such paths. From their first divergence, follow one path until it next touches the other. The two segments between those vertices share only their endpoints, so they form a cycle. Acyclicity therefore makes the simple path unique. Conversely, if a cycle exists, choose two adjacent vertices on it. We can take their edge or go around the rest of the cycle. A forest consists of tree components. In an unrooted tree, a vertex of degree at most one is a leaf, so the singleton tree has one leaf.

A **rooted** tree distinguishes one vertex as the root. From any other vertex, take the first step of the unique path back to the root. That step gives its parent. The length of the whole path is the vertex's depth. The largest depth is the height of the rooted tree. An **ordered** rooted tree also gives the children of each vertex an order. If the root has children $a,b$ and only $a$ has a child, exchanging their order changes an ordered tree but leaves the same rooted tree up to isomorphism. To represent the tree by prefixes, record the child positions along the path from the root to each vertex. Erase the last position to recover its parent.

In the perfect binary tree $B_h$, $0$ and $1$ name the two child directions. Vertices are $\{0,1\}^{\le h}$. If $|u|<h$, attach the two children obtained by appending one bit, $u0$ and $u1$. The empty word is the root, and the $2^h$ words of length $h$ are the leaves. The level counts add to $1+2+\cdots+2^h=2^{h+1}-1$. For $h>0$ the root has degree two, the other internal vertices degree three, and the leaves degree one. For $h=0$ the unique vertex has degree zero.

**Constructing a spanning tree.** Start at one vertex $s$ with no edges. If the graph is connected and there is an unvisited vertex, some path from $s$ to it must leave the visited set for the first time. Add that boundary edge and its new endpoint. The new vertex is attached by exactly one edge in the growing subgraph, so connectivity is preserved and a cycle cannot be created. Adding one vertex and one edge keeps the equation $|V_i|=|E_i|+1$. When all vertices have been added, the result is a tree with the original vertex set and $|V|-1$ edges.

Consequently a finite connected graph has at least $|V|-1$ edges. Any additional edge closes a cycle with the tree's unique path between its endpoints. In a forest with $k$ components, apply the tree count in each component and add, obtaining $|E|=|V|-k$. Thus any two of connectedness, acyclicity and $|E|=|V|-1$ imply the third. The equation alone is insufficient. A triangle disjoint from a one-edge path has five vertices and four edges while being both disconnected and cyclic.

::: practice Remove an edge from a tree
Why does removing any edge $\{u,v\}$ leave exactly two components?
::: answer
The edge itself was the unique simple $u$–$v$ path, so its removal separates $u$ and $v$. Every other vertex has a path to $u$. If that path used the removed edge, its segment up to $v$ is still a path to $v$. Hence each vertex is connected to one of the two endpoints. Neither component can contain a cycle, so both are trees.
:::

## 10.3 Breadth-First and Depth-First Search

The spanning tree proof leaves a choice. Which visited vertex should supply the next edge to an unvisited vertex? Let $u_1,\ldots,u_i$ be the vertices in discovery order. Among those with an unvisited successor, breadth-first search (BFS) chooses the **earliest** $u_j$, and depth-first search (DFS) chooses the **latest**. If several successors remain, the smallest label makes the trace deterministic. Only discovery edges are recorded in the tree. An edge to a known vertex has no role in adding a new one.

Take edges $\{01,02,13,24,34\}$, abbreviated to their endpoint labels, and start at 0.

| Discovery time | BFS edge | DFS edge |
| --- | --- | --- |
| $2$ | $0\to1$ | $0\to1$ |
| $3$ | $0\to2$ | $1\to3$ |
| $4$ | $1\to3$ | $3\to4$ |
| $5$ | $2\to4$ | $4\to2$ |

Stop at time 3. The discovery list is still $0,1$ for both searches. Vertex 0 has 2 available, and vertex 1 has 3. BFS goes back to 0 because it was found first. DFS continues from 1 because it was found last. Both trees eventually span the same five vertices. BFS reaches them in distance order, while DFS pursues a branch before resuming an earlier one.

Why does BFS find vertices in distance order? Start with distance zero, where the start vertex is the entire layer. At the start of layer $d$, all vertices through distance $d$ have been discovered, and the earlier layers have no unvisited successors left. BFS handles the vertices at distance $d$ before using any newly discovered vertex as a parent. An edge out of this layer reaches at distance at most $d+1$. Conversely, the last edge of any shortest path of length $d+1$ comes from this layer. Thus the new discoveries are exactly the vertices at distance $d+1$, each attached by a shortest route in the tree.

For either search, every discovery edge follows the original direction and keeps the new vertex in $sE^*$. If we stopped with a reachable vertex still unseen, a path to it would have a first edge from a visited vertex to an unseen one. That edge would still be available. So the tree spans exactly $sE^*$. In a disconnected simple graph, restarting in another component gives a spanning forest.

On $K_n$, any visited vertex can reach any remaining vertex in one step. This makes the choice of parent determine the entire shape. BFS always extends from the start and returns a star. DFS always extends from the most recently discovered vertex and returns a path. Both statements hold with any tie-breaking order.

## 10.4 Degree Sequences, Complements, and Havel–Hakimi

Count incidences $(v,e)$ with $v\in e$. Counting by vertex gives $\sum_v\deg(v)$. Counting by edge gives two per edge. Thus

$$
\sum_{v\in V}\deg(v)=2|E|.
$$

The number of odd-degree vertices is even because the sum is even. In a tree on $n\ge2$ vertices this sum is $2n-2$ and no degree is zero. If there were at most one degree-one vertex, the sum would be at least $1+2(n-1)=2n-1$, a contradiction. If there are exactly two leaves, every other degree must be exactly two to obtain the required sum. A longest path in that tree must then contain all vertices: its endpoints are leaves, and any connection from an omitted vertex to the path would give an internal vertex a third neighbour.

For an ascending degree sequence $(d_1,\ldots,d_n)$, test first that $0\le d_i\le n-1$ and the sum is even. These are necessary, and do not ensure realization. **Havel–Hakimi** removes one vertex of largest degree $d_n$ and subtracts 1 from the $d_n$ largest of the remaining degrees. Resort and repeat. A negative entry or out-of-range degree is failure. An all-zero list succeeds. To construct a graph, preserve vertex labels so the selected neighbours can be connected to the removed vertex while unwinding the recursion.

Try $(1,1,2,2,2)$. Name the degree-one vertices $a,b$ and the degree-two vertices $u,v,w$. Remove $w$ and reduce the degrees of $u,v$ to 1. The remainder is $(1,1,1,1)$. If its edges are $\{a,u\},\{b,v\}$, adding $\{w,u\},\{w,v\}$ gives the path $(a,u,w,v,b)$. If the remainder pairs $u$ with $v$ and $a$ with $b$, the same two added edges give a triangle and a separate edge. Both are realizations, and their component counts certify that they are nonisomorphic.

Why may we choose the largest remaining neighbours? Start with any realization and fix a vertex $u$ of largest degree. If a desired neighbour $v$ is missing, some unchosen vertex $w$ is there in its place. Since we chose the largest remaining degrees, $\deg(v)\ge\deg(w)$. We want to trade the edge $uw$ for $uv$. That leaves $w$ short one edge and gives $v$ one too many. We need a neighbour $x$ of $v$ whose edge can go to $w$ instead.

Compare the neighbour sets of $v$ and $w$ after excluding each other. The set for $w$ contains $u$, and the set for $v$ is at least as large and omits $u$. So $v$ must have a neighbour $x$ in its set that is absent from $w$'s. Replace $uw,vx$ by $uv,wx$. Both new edges were absent. Each of the four vertices loses one edge and gains one edge, and now $u$ has one more of its desired neighbours. Repeating gives a realization with the desired adjacency, proving that deleting $u$ loses no feasible degree sequence. Conversely a reduced realization gives the original by reversing the removal.

For the complement $\overline G=(V,\binom V2\setminus E)$, every vertex has complementary degree $n-1-\deg(v)$. Hence the complement's ascending degree list is $(n-1-d_n,\ldots,n-1-d_1)$. Also the degrees 0 and $n-1$ cannot coexist: the universal vertex would connect to the isolated one. On $n\ge2$ vertices there are therefore at most $n-1$ degree values actually available, forcing a repeated degree.

::: practice An even sum that fails
Decide whether $(1,1,3,3)$ can occur.
::: answer
The sum is even and the largest degree equals $4-1$. Remove a 3 and subtract 1 from all three remaining entries. Sorting gives $(0,0,2)$. The next step subtracts 1 from both zeros, so the sequence fails. Equivalently, the two degree-three vertices would force both other vertices to have degree at least two.
:::

## 10.5 Catalan Numbers and Counting Labeled Trees

A full ordered binary tree has either no children or two ordered children at every vertex. With $n$ internal vertices it has $2n$ edges and $2n+1$ vertices. Look at its recursive description. A leaf has empty description $\varepsilon$. An internal vertex with left and right descriptions $u,v$ is encoded as $[u]v$. To reverse the encoding, find the first opening bracket's matching close. Its interior is the left description and the suffix is the right description. This recovers the tree uniquely. With two internal vertices, putting the root's internal child on the left gives $[[]]$ and putting it on the right gives $[][]$. These are two different **Dyck words**, the well-formed bracket words. Each internal vertex contributes one pair, so the words of length $2n$ count trees with $n$ internal vertices.

There are $\binom{2n}{n}$ words with exactly $n$ opening and $n$ closing brackets. Some fail because a prefix contains more closes than opens. Factor the word as $u\,]\,v$ at its first failure. At that point $u$ is balanced and the next closing bracket puts us one below zero. The rest of the word must contain one more open than close to get back to zero.

Keep that first failure where it is and swap the brackets in the **remaining suffix** $v$. The suffix now has one extra close as well. We finish with two more closes than opens, or $n-1$ opens and $n+1$ closes. To go back, start with a word with that imbalance and find its first failure. None of the earlier brackets move in the swap, so this is the same point at which to reverse the suffix. The inverse recovers a bad balanced word. Subtracting the bad words therefore gives the Catalan number

$$
C_n=\binom{2n}{n}-\binom{2n}{n+1}=\frac{1}{n+1}\binom{2n}{n}.
$$

::: manim ch10_catalan_reflection.mp4 | Reflect at the first bad closing bracket
Read an opening bracket as a horizontal step and a closing bracket as a vertical step. The red step stays fixed. Reflecting the remaining suffix changes the endpoint from $(3,3)$ to $(2,4)$.
:::

For $n=0$ the empty word encodes the one-vertex tree, and the formula gives $C_0=1$. Here $C_n$ counts trees. In graph-family notation the same symbol names the cycle graph on $n$ vertices.

Cayley's problem is different. The vertices are distinguishable labels in $[n]$, and a tree is counted by its actual set of edges. For $n\ge2$, fix a positive degree list $d_1,\ldots,d_n$ summing to $2n-2$. Let $N(n;d_1,\ldots,d_n)$ count its labeled trees. Moon's formula is

$$
N(n;d_1,\ldots,d_n)=\binom{n-2}{d_1-1,\ldots,d_n-1}.
$$

The base case $n=2$ is the single edge. For $n>2$, the degree sum guarantees a degree-one entry. Fix that leaf label. Its neighbour must have degree at least two, since two adjacent degree-one vertices would form an entire component. Once we choose a neighbour $i$, deleting the leaf reduces just $d_i$ by one. Reattaching it at $i$ reverses that deletion, so the induction counts exactly the trees with that chosen neighbour.

Write $r_i=d_i-1$. In the multinomial count for the smaller tree, the entry $r_i$ becomes $r_i-1$, giving $(n-3)!/((r_i-1)!\prod_{j\ne i}r_j!)$ for each $i$ with $r_i>0$. Relative to the common factor $(n-3)!/\prod_j r_j!$, that reduction contributes a multiplier $r_i$. Adding over all possible neighbours gives the multiplier $\sum_i r_i=n-2$. This turns $(n-3)!$ into $(n-2)!$ as required.

To count all labeled trees, let the degree list vary. A term with entries $r_i$ is the number of words of length $n-2$ in which letter $i$ occurs $r_i$ times. Every word has one such profile. Summing the terms therefore gives $n^{n-2}$, the number of words with $n$ choices at every position. For $n=1$ there is one tree with no edges.

::: practice Why the tree labels matter
How many trees on $[4]$ have degree sequence $(1,1,2,2)$ when sorted? What if the vertices of degree two are prescribed?
::: answer
For fixed degree-two labels the multiplicities are two ones and two zeros, so Moon's formula gives $\binom2{1,1,0,0}=2$. There are $\binom42=6$ choices of which labels have degree two, giving 12 labeled paths. They are all isomorphic. Adding the four stars makes $16=4^{4-2}$ labeled trees.
:::
