Keep the arrows from Chapters 4 and 5. This time we draw them from a set of inputs to a set of outputs, and every input gets exactly one arrow. Now stand at an output and try to go back. There might be several arrows to choose from, or none. Looking in these two directions will tell us when an output determines its input, and eventually whether two sets can be matched element for element.

## 6.1 A function gives exactly one output to each input

A relation can connect the same input to two outputs, or leave it unconnected. A function $f:A\to B$ is a relation $f\subseteq A\times B$ in which every $a\in A$ has exactly one successor. In the notation of Chapter 4, $|af|=1$. Write $f(a)$ for that unique output, so $afb$ means $f(a)=b$. A partial function requires only $|af|\le1$, so an input may be missing an output. The condition controls outgoing arrows. Several inputs may point to the same output.

Take the real unit circle as a relation between coordinates. At $x=0$, the relation $x^2+y^2=1$ gives two outputs $y=-1,1$. Keep the upper half by requiring $y\ge0$. That leaves at most one output for each real $x$.

Try $x=2$ now. There is still no point above it on the circle. To guarantee an output at every input, we have to cut down the input set as well, to $[-1,1]$. This gives the total function $x\mapsto\sqrt{1-x^2}$. The first change gave uniqueness. The second gave existence on the chosen domain.

The **domain** is $A$, the **codomain** is $B$, and the **image** $\mathrm{im}(f)=\{f(a)\mid a\in A\}$ is the part of $B$ that the function actually reaches. A finite value table contains the domain and all outputs. It usually does not determine the declared codomain. In a bipartite graph, draw one side for each set, including the unreachable vertices of the codomain. A plot of real input/output pairs shows the same graph geometrically. The vertical-line test asks whether an input has more than one output. Totality asks separately whether every required input is represented.

The function space $B^A$ contains all functions from $A$ to $B$. If $A=[n]$, choosing its outputs is equivalent to choosing an $n$-tuple of elements of $B$. For finite sets this gives $|B^A|=|B|^{|A|}$. When the domain is empty, there is one function with no pairs. The characteristic function $\delta_T:A\to\{0,1\}$ records a subset $T\subseteq A$ by outputting $1$ exactly on $T$. A multiset instead records a nonnegative multiplicity per object with a function $A\to\mathbb N_0$. The output meaning decides whether we are recording membership or multiplicity.

A function with domain $A_1\times\cdots\times A_k$ takes a tuple as input. Its **arity** is $k$, and we usually write $f(a_1,\ldots,a_k)$ for its value. If all input sets and the output set equal $A$, it is a $k$-ary operation on $A$. Recall the empty tuple from Chapter 2. A nullary function receives that one tuple, so it still gives one answer. That answer is the constant it selects.

For a binary operation $\diamond:A\times A\to A$, the same function value can be written in infix form $a\diamond b=\diamond(a,b)$. Four rules answer four different questions about the operation.

| Rule | Test for every allowed input |
| --- | --- |
| Associative | $(a\diamond b)\diamond c=a\diamond(b\diamond c)$ |
| Commutative | $a\diamond b=b\diamond a$ |
| Idempotent | $a\diamond a=a$ |
| Left or right neutral element | $e_\ell\diamond a=a$ or $a\diamond e_r=a$, respectively |

On $2^A$, union and intersection each satisfy the first three rules. Their neutral elements are $\varnothing$ for union and $A$ for intersection, on either side. For difference, $X\setminus\varnothing=X$ but $\varnothing\setminus X=\varnothing$. Thus $\varnothing$ is right neutral and, when $A$ is nonempty, fails the left-neutral test. Check associativity on a nonempty $X$: $(X\setminus X)\setminus X=\varnothing$, while $X\setminus(X\setminus X)=X$.

::: practice Change the domain and retest
Consider the relation $xy=1$ with both coordinates real. Is it a partial function? For what input domain does it become total?
::: answer
For nonzero $x$ the unique output is $1/x$. There is no output for $x=0$, so the relation is a partial function over $\mathbb R$ and a total function from $\mathbb R\setminus\{0\}$ to $\mathbb R$. Removing $0$ from the codomain would leave the pairs unchanged because no output is $0$.
:::

## 6.2 Composition reads from the inner application out

Suppose $f:A\to B$ and $g:B\to C$. Starting at $a$, first ask $f$ for a value in $B$. That result is a valid input for $g$. Thus $(g\circ f)(a)=g(f(a))$. Read “$g$ after $f$.” In the relational-product convention from Chapter 4 the same two arrow steps form $fg$. Tracing a point makes the two writing orders easy to distinguish.

Take $f(a)=1,f(b)=1,f(c)=2$ and $g(1)=\beta,g(2)=\gamma,g(3)=\alpha$. Composing gives $a\mapsto\beta,b\mapsto\beta,c\mapsto\gamma$. The input $3$ is available to $g$, but composing with $f$ never reaches that row. In the Boolean matrices, the row for $a$ in $M_f$ selects row $1$ of $M_g$, so $M_{g\circ f}=M_fM_g$. Exactly one row is selected because $f$ is a function.

Composition is associative when all types fit. Both bracketings send $a$ to $h(g(f(a)))$. It is generally not commutative, even for two self-maps. On $\mathbb Z$, if $f(x)=x+1$ and $g(x)=2x$, then $g(f(0))=2$ and $f(g(0))=1$. The identity $\mathrm{Id}_A$ returns each input unchanged, so it can be inserted on the matching side of any composition.

## 6.3 Injectivity, surjectivity, and inverse functions

Now turn attention to the receiving side. A function $f:A\to B$ is **injective** when each $b\in B$ has at most one predecessor. It is **surjective** when each $b\in B$ has at least one predecessor. A **bijection** has exactly one predecessor for every $b$. For the finite map in §6.2, the shared output $1$ witnesses the failure of injectivity of $f$. If $B=\{1,2,3\}$, the unreached $3$ witnesses the failure of surjectivity. Restricting the codomain to $\{1,2\}$ fixes the second failure and leaves the first one in place.

To prove injectivity directly, start from $f(a)=f(a')$ and work toward $a=a'$. To prove surjectivity, start with an arbitrary allowed target $b$ and find an input satisfying $f(a)=b$. For $f(x)=2x+1$ from $\mathbb Z$ to $\mathbb Z$, equality of outputs cancels the $1$ and then the nonzero factor $2$, establishing injectivity. The output $0$ would require $x=-1/2$, which is outside the domain. To make this map surjective, use $2\mathbb Z+1$ as the codomain. Given any element $2k+1$ of that set, the integer $k$ supplies the required preimage.

Composition of two injective maps is injective because equality of the final outputs can be cancelled one map at a time. Composition of two surjective maps is surjective because a preimage of the target can be found first through $g$ and then through $f$. If $g\circ f$ is injective, $f$ must be injective: any collision at the intermediate stage also collides at the end. If $g\circ f$ is surjective, $g$ must be surjective because every final value has already been produced by $g$. These reverse arguments control a specific factor.

For a bijection, reverse each arrow to obtain the inverse function $f^{-1}:B\to A$. Every reverse arrow has an unambiguous answer because every target has exactly one predecessor. Then $f^{-1}\circ f=\mathrm{Id}_A$ and $f\circ f^{-1}=\mathrm{Id}_B$. For the odd-integer map, $f^{-1}(y)=(y-1)/2$ is an integer on exactly the declared codomain. On coordinate plots, reversing the pairs swaps $x$ and $y$, reflecting the graph in the diagonal. A non-bijective function still has well-defined **preimage sets**, which may contain several points or none.

If $g:B\to A$ satisfies $g\circ f=\mathrm{Id}_A$, applying $g$ cancels any proposed collision, so $f$ is injective. If $f\circ g=\mathrm{Id}_B$, each $g(b)$ supplies a preimage of $b$, so $f$ is surjective. For a bijective $f$, either identity alone gives $g=f^{-1}$. For example, $f\circ g=\mathrm{Id}_B$ gives $g=f^{-1}\circ(f\circ g)=f^{-1}$. The left-identity case works by composing on the right. For bijections $f:A\to B$ and $g:B\to C$, undo the $g$ step first and the $f$ step second, so $(g\circ f)^{-1}=f^{-1}\circ g^{-1}$.

A strictly increasing function between total orders is injective because any distinct inputs are strictly ordered and then have strictly ordered outputs. Restrict its codomain to its image to obtain a bijection. The inverse is strictly increasing as well. For $y<y'$ write $x=f^{-1}(y)$ and $x'=f^{-1}(y')$. If $x\ge x'$, monotonicity would give $y\ge y'$. A strictly decreasing bijection has a strictly decreasing inverse by the same argument with the direction reversed.

## 6.4 Images and preimages of sets

Suppose the domain is $A=\{1,2,3,4,5\}$ and the outputs are $f(1)=f(5)=r$, $f(2)=f(4)=g$, and $f(3)=b$, with codomain $B=\{r,g,b,y\}$. For $X=\{1,4\}$, following the two arrows gives $f(X)=\{r,g\}$. Now reverse direction. Every input landing at either $r$ or $g$ belongs to the preimage, so $f^{-1}(\{r,g\})=\{1,2,4,5\}$. The round trip added inputs that share the outputs.

::: manim ch06_image_preimage.mp4 | Follow an image and come back
The yellow arrows give the image of the chosen inputs. The blue arrows discover two more inputs that reach the same outputs. The isolated target has no preimage.
:::

For $X\subseteq A$ and $Y\subseteq B$, the precise definitions are

$$
f(X)=\{f(a)\mid a\in X\}=Xf,\qquad
f^{-1}(Y)=\{a\in A\mid f(a)\in Y\}=fY.
$$

When is the entire image of $X$ inside $Y$? Exactly when the arrow from every $a\in X$ arrives in $Y$. Those are precisely the inputs in $f^{-1}(Y)$. So $f(X)\subseteq Y$ iff $X\subseteq f^{-1}(Y)$. One failed arrow disproves either statement.

Let's read the two round trips. Start with $X$ and follow its arrows forward. On the way back, every original input qualifies because its own output is among the ones we reached. Other inputs may share those outputs. So $X\subseteq f^{-1}(f(X))$. If two inputs share an output, put just one of them in $X$. The return trip picks up the other one too.

Start at $Y=\{b,y\}$ and go backwards first. There is an arrow into $b$, and there is none into $y$. Coming forward again gives only $\{b\}$. Every arrow we followed back came from a target in $Y$, so $f(f^{-1}(Y))\subseteq Y$. A singleton containing an unreached target already makes this strict. Thus the first inclusion is equality for all $X$ exactly when $f$ is injective, and the second is equality for all $Y$ exactly when $f$ is surjective.

With relational notation, $ff^\top$ acts on inputs and relates two inputs exactly when they share an output. Thus $\mathrm{Id}_A\subseteq ff^\top$, with equality exactly for injectivity. In the opposite direction $f^\top f$ acts on outputs. An input has one output, so this product contains only loops, one for each reachable target. Thus $f^\top f\subseteq\mathrm{Id}_B$, with equality exactly for surjectivity. A further forward step from any input in the same output class always returns that same value, giving $ff^\top f=f$. Reversing this equality gives $f^\top ff^\top=f^\top$.

Preimages preserve union, intersection, and difference. For intersection, reason on one input: $a$ belongs to $f^{-1}(Y\cap Y')$ exactly when the single value $f(a)$ belongs to both $Y$ and $Y'$. Thus $a$ is in both preimages. Replacing “both” with the appropriate logical test proves the other two laws. Images preserve union, but an output can come from different witnesses in two source sets. In our example $\{1\}\cap\{5\}=\varnothing$, while $f(\{1\})\cap f(\{5\})=\{r\}$. In general,

$$
f(X\cap X')\subseteq f(X)\cap f(X'),\qquad
f(X\setminus X')\supseteq f(X)\setminus f(X').
$$

Why do the inclusions point in different directions? An input in $X\cap X'$ supplies one arrow that works for both images. A value in both images may have two separate witnesses, as $r$ did. For difference, begin with a value in $f(X)\setminus f(X')$. Its witness in $X$ cannot belong to $X'$ because the value is absent from $f(X')$. So that witness belongs to $X\setminus X'$. In the other direction, an input can survive $X\setminus X'$ and still share its output with an input in $X'$.

Injectivity makes both inclusions equalities because each output has at most one witness. Conversely, a shared value $b=f(a)=f(a')$ with $a\ne a'$ breaks both equalities for $X=\{a\}$ and $X'=\{a'\}$. A complement identity for every $X$ also requires surjectivity. At $X=\varnothing$, the identity asks for the image of all of $A$ to equal all of $B$. With a shared value, the complement of $\{a\}$ still maps to $b$ via $a'$, even though the complement of $f(\{a\})$ excludes $b$. A bijection preserves complements by the difference law and $f(A)=B$.

Grouping inputs by equal output gives the equivalence relation $a\equiv_f a'$ iff $f(a)=f(a')$. Its classes are the nonempty preimages of single values. The map $a\mapsto[a]_f$ is surjective onto the quotient because every class has a representative. The map $\tilde f:[a]_f\mapsto f(a)$ is well-defined by equality of outputs within a class and injective because different classes have different outputs. Together the maps recover $f(a)=\tilde f([a]_f)$. This is the reason grouping records by a key leaves one group per key that actually occurs.

## 6.5 Self-maps, orbits, and permutations

A self-map $f:A\to A$ can be applied repeatedly. Its orbit starting at $a$ is $a,f(a),f^2(a),\ldots$ with $f^0=\mathrm{Id}_A$. Here an exponent counts applications. If two entries coincide, the later successors repeat because each current point has only one next point. For a finite set this gives a cycle after a possible initial tail. If the map is injective, cancellation shows that the orbit was on the cycle from the start. Indeed from $f^i(a)=f^j(a)$ with $i<j$ we get $a=f^{j-i}(a)$ by cancelling $i$ applications.

A permutation is a bijective self-map. On a finite set, injectivity or surjectivity alone already implies bijectivity. For injectivity, $|A|$ distinct inputs produce $|A|$ distinct outputs in $A$, so none are missing. For surjectivity, exactly $|A|$ input arrows are needed to cover the $|A|$ targets, so no two can land at one target. This argument needs finiteness. The self-map $n\mapsto n+1$ on $\mathbb N_0$ is injective and misses $0$.

Write a finite map in two-line notation with inputs in the top row and their outputs directly below. One-line notation lists only the outputs and relies on a fixed input order. For a permutation, cycle notation follows the arrows until they return to the start. For example,

$$
f=\begin{pmatrix}1&2&3&4&5&6&7\\4&5&2&7&3&6&1\end{pmatrix}
=(1,4,7)(2,5,3)(6).
$$

The first cycle says $1\mapsto4$, $4\mapsto7$, $7\mapsto1$. A rotation such as $(4,7,1)$ describes those same arrows. Reversing the cycle gives the inverse arrows. The fixed point $6$ may be omitted when the carrier is understood. Disjoint cycles can be listed in any order since they act on disjoint groups of points.

::: manim ch06_permutation_cycles.mp4 | From a table to disjoint cycles
Follow the arrows from one unused entry until it returns. When composing the two permutations near the end, look at the intermediate value after applying the rightmost map.
:::

Let $g=(1,4)(2,6)(3,7,5)$. Start at $1$ and read the rightmost map first. From $g$ we get $g(1)=4$. Pause there. The $4$ is the input to $f$, so $f(4)=7$ is where the first arrow of $f\circ g$ ends.

Now start the same two-step procedure from $7$. It gives $7\mapsto3$ because $g(7)=5$ and $f(5)=3$. From $3$ we return to $1$. Repeating for unused entries gives $(f\circ g)=(1,7,3)(2,6,5)(4)$. If the order is hard to remember, write the intermediate value before drawing each arrow of the composite.

Iteration can also be studied for a non-bijective map on an infinite set. The Collatz self-map on $\mathbb N$ sends even $n$ to $n/2$ and odd $n$ to $3n+1$. Starting at $3$ gives $3,10,5,16,8,4,2,1,4,\ldots$. That trace reaches the cycle $4,2,1$. Whether every starting value reaches it is the open question. The graph makes a verified finite trace visible without turning it into a general proof.

::: practice Trace the order explicitly

For $p\circ q$, $1\mapsto3$ through $2$, $3\mapsto1$ through $3$, and $2\mapsto2$ through $1$. So $p\circ q=(1,3)$. For $q\circ p$, $1\mapsto1$ through $2$, $2\mapsto3$ through $3$, and $3\mapsto2$ through $1$. So $q\circ p=(2,3)$.
:::
