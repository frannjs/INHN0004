A satisfying assignment for a scheduling problem tells us where to put each lecture. What do we show if no schedule fits? We want a chain of inferences someone can check without running the search again. DPLL searches for an assignment and resolution gives us a way to prove that none works. Later we’ll use first-order logic to talk about objects, relations, and witnesses without naming every possible object in advance.

## 15.1 SAT Modeling, DPLL, and Horn Formulas

### Make the variables describe a candidate solution

The satisfiability problem (SAT) asks whether a given propositional formula has a satisfying assignment. To turn a coloring problem into SAT, first decide what a $1$ in an assignment will tell us. Let $C_{v,i}$ mean that vertex $v$ receives color $i$ in $\{1,2,3\}$. We can read the assigned color from these three variables if exactly one of them is true. The clause $C_{v,1}\lor C_{v,2}\lor C_{v,3}$ requires a choice, and $\neg C_{v,i}\lor\neg C_{v,j}$ for each pair $i<j$ prevents two choices.

Now look at an edge $\{u,v\}$. Can both endpoints take color $2$? The clause $\neg C_{u,2}\lor\neg C_{v,2}$ excludes exactly that pair of choices. Add the same condition for each color at each edge. A proper coloring tells us which variables to make true and satisfies all these clauses. Conversely, a satisfying assignment tells us which single color to read at each vertex, and the edge clauses guarantee those colors give a proper coloring. We now have a way to recover the object we asked for.

For a Hamiltonian cycle, use $X_{v,i}$ to say vertex $v$ occupies position $i$ in a cyclic listing. Hold the position fixed to require exactly one vertex in it. Then hold the vertex fixed to require exactly one position for it. These conditions give a listing with each vertex once. For each ordered pair $(u,v)$ with no allowed edge and each consecutive pair of positions $i,i+1$, add $\neg X_{u,i}\lor\neg X_{v,i+1}$. Treat the last and first positions as consecutive too. That last adjacency requirement is the one that closes the listing into a cycle.

### Two empty objects with opposite meanings

Represent a CNF as a set of clauses $\mathcal K$. Each clause $C$ is a set of literals and represents their disjunction. The whole set represents the conjunction of those clauses. For instance $\{\{p,\neg q\},\{q\}\}$ means $(p\lor\neg q)\land q$. A clause containing both $L$ and its dual $\overline L$ is always true and can be omitted.

Be careful when the algorithm crosses out its last item:

| Object | What is empty? | Value |
|---|---|---|
| $\varnothing$ | The clause set. No clauses remain to be satisfied. | $\top$ |
| $\{\varnothing\}$ | A clause inside the set. No literals remain that could satisfy it. | $\bot$ |

Once a clause set contains the empty clause, adding other clauses cannot help. This distinction governs the stop conditions.

### Simplify after one assignment and keep the reason

Suppose we’ve just made $L$ true. A clause containing $L$ is already satisfied. Cross out the whole clause. Now stay inside the clauses that remain. There we cross out only $\overline L$, since it can no longer make its clause true. The remaining clause set describes exactly the extensions of the chosen assignment that satisfy the original.

If we crossed out the last clause, the branch succeeded. If we crossed out the last literal of a clause that still has to be satisfied, the branch failed. The two levels of the set tell us which happened.

The basic DPLL algorithm selects a variable $p$, simplifies once with $p=1$ and once with $p=0$, and returns satisfiable if one branch succeeds. Every assignment sets $p$ one way or the other, so the two branches exhaust the possibilities. The following reductions can avoid a branch:

- **One-literal rule (OLR).** If $\{L\}\in\mathcal K$, every model must make $L$ true. Make that assignment.
- **Pure-literal rule (PLR).** If $L$ occurs but $\overline L$ does not, making $L$ true cannot turn a true clause false. If a model exists with $L$ false, change its variable to make $L$ true and the result is still a model. This choice preserves satisfiability, though it may discard some models.

Use OLR first, then PLR, and branch if no reduction applies. When a task specifies how to break ties or which truth value to try first, use that order. At each edge in a trace record both the rule and the literal assigned. To recover a model, follow the successful path from the root and collect only the assignments on that path. You can choose values freely for variables the path never sets.

For a small run, take
$$
\mathcal K=\{\{\neg p,q,\neg r,s\},\{\neg q,\neg r,s\},\{r\},\{\neg p,\neg s\},\{\neg p,r\}\}.
$$
OLR sets $r=1$. Delete the two clauses made true by $r$, and remove $\neg r$ from the first two. This leaves $\{\{\neg p,q,s\},\{\neg q,s\},\{\neg p,\neg s\}\}$. The literal $\neg p$ is pure. Set it true to keep only $\{\{\neg q,s\}\}$. Now $\neg q$ is pure. Setting it true empties the set. Both choices for $s$ work with $r=1,p=q=0$.

### Horn clauses let forced truth do the work

In the propositional case, a Horn clause has at most one positive literal. Write $\{\neg A_1,\ldots,\neg A_k,B\}$ as $(A_1\land\cdots\land A_k)\to B$. With no positive literal use $\bot$ as the conclusion. A positive unit $B$ is a fact with no premises. For example, with facts $p$ and $q$ and rule $(p\land q)\to r$, $r$ is forced. If $(r\land q)\to\bot$ is also present, the derived truths give a contradiction.

Start with positive facts and repeatedly apply any rule whose premises have all become true. Those conclusions hold in every model, by induction on the derivation. Reaching $\bot$ proves impossibility. If no rule applies and no contradiction has been derived, set every underived variable to false. A rule with a false premise is satisfied. A rule whose premises are all true already has its conclusion in the derived set. Thus the resulting assignment is a model, and its true set is contained in every model. This explains why positive unit propagation suffices for Horn satisfiability.

### Cardinality clauses and why negative-first DPLL avoids backtracking on Horn sets

Word problems in SAT modelling often bound how many variables in $S=\{X_1,\ldots,X_m\}$ may hold simultaneously:

- **At least one:** the single clause $X_1\lor\cdots\lor X_m$.
- **At most one:** $\neg X_i\lor\neg X_j$ for every $1\le i<j\le m$ ($\binom m2$ binary clauses).
- **At most $k$ ($1\le k<m$):** rule out every $(k+1)$-element subset $U\subseteq S$ with the clause $\bigvee_{X\in U}\neg X$ ($\binom{m}{k+1}$ clauses; for instance, "at most two of $A,B,C$ are true" is the single clause $\neg A\lor\neg B\lor\neg C$).
- **At least $k$:** equivalently, at most $m-k$ variables are false, giving $\bigvee_{X\in W}X$ for every $(m-k+1)$-subset $W\subseteq S$.

Watch how tie-breaking interacts with DPLL on a Horn clause set $\mathcal K$. If we branch **positive-first** ($[\top/A]$), even a satisfiable Horn set such as $\{\{\neg A,B\},\{\neg B,C\},\{\neg C,A\},\{\neg A,\neg C\}\}$ backtracks: neither OLR nor PLR applies initially, trying $A=1$ forces $B=1$ and $C=1$ into $\{\varnothing\}$, and only after backtracking does $A=0$ succeed. By contrast, if DPLL (with OLR before PLR) always branches **negative-first** ($[\bot/A]$), it **never backtracks** on any Horn clause set:

- **Why:** Deleting clauses or literals from a Horn set leaves a Horn set. Whenever OLR does not apply, every remaining clause has size at least $2$. Since a Horn clause contains at most one positive literal, **every remaining clause contains at least one negative literal**, so setting all remaining variables to $0$ satisfies $\mathcal K$. Choosing $A=0$ at the split therefore always lands in a satisfiable $(n-1)$-variable Horn set, which by induction finishes along a single path without backtracking.

## 15.2 Propositional Resolution

### Eliminate a choice while keeping its consequence

Suppose we know $p\lor q$ and $\neg p\lor r$. If $p$ is false, the first clause forces $q$. If $p$ is true, the second forces $r$. Consequently $q\lor r$ holds either way. The resolution rule packages this case split. For $L\in C_1$ and $\overline L\in C_2$, the resolvent is
$$
R=(C_1\setminus\{L\})\cup(C_2\setminus\{\overline L\}).
$$
Only **one** complementary pair is removed in a step. If every remaining literal were false, $C_1$ would require $L$ and $C_2$ would require $\overline L$. This is impossible. Thus $\{C_1,C_2\}\models R$. Adding the resolvent leaves the models of the current clause set unchanged.

Consider $\{p,q\}$ and $\{\neg p,\neg q\}$. Both hold for $(p,q)=(1,0)$, so removing both complementary pairs would incorrectly produce the empty clause. Correctly resolving on $p$ gives $\{q,\neg q\}$, which is always true. On $q$ it instead gives $\{p,\neg p\}$. The rule is sound because one pivot has two cases that we can track.

### Read a refutation as a graph of reasons

Take the following given clauses.
$$
\{\neg q,s\},\quad \{\neg p,q,s\},\quad \{p\},\quad
\{r,\neg s\},\quad \{\neg p,\neg r,\neg s\}.
$$
The first two clauses share $s$ and contain opposite signs of $q$. Resolve on $q$ and keep one copy of $s$. The last two clauses share $\neg s$ and contain opposite signs of $r$. We’re aiming for conflicting requirements on $s$. To draw the proof, give each resolvent one incoming arrow from each parent.

| Parents | Pivot variable | Resolvent |
|---|---|---|
| $\{\neg q,s\}$ and $\{\neg p,q,s\}$ | $q$ | $\{\neg p,s\}$ |
| $\{r,\neg s\}$ and $\{\neg p,\neg r,\neg s\}$ | $r$ | $\{\neg p,\neg s\}$ |
| $\{p\}$ and $\{\neg p,s\}$ | $p$ | $\{s\}$ |
| $\{p\}$ and $\{\neg p,\neg s\}$ | $p$ | $\{\neg s\}$ |
| $\{s\}$ and $\{\neg s\}$ | $s$ | $\varnothing$ |

The two unit clauses at the end require opposing values of $s$. Their resolvent $\varnothing$ is the empty **clause**. It has no satisfying assignment. The original set entails every node reachable by these inference steps, so it also has no satisfying assignment. To show $F_1,\ldots,F_k\models G$, instead refute a clause encoding of $F_1\land\cdots\land F_k\land\neg G$. An equisatisfiable encoding is sufficient for finding a contradiction there.

::: manim ch15_resolution.mp4 | A resolution refutation one pivot at a time
Follow the two separate consequences of the premise $\{p\}$. They end at conflicting requirements on $s$. The incoming arrows at the final node identify the two premises of the last step.
:::

In **positive resolution**, one parent of every step must contain only positive literals. For example $\{p,q\}$ is a positive parent for resolving with $\{\neg q,r\}$ on $q$. The new clause $\{p,r\}$ is positive and can be used as a parent in a later step. In contrast, the first step of the refutation above has a negative literal in each parent. To adapt that graph, start with $\{p\}$ and resolve it with $\{\neg p,q,s\}$ and $\{\neg p,\neg r,\neg s\}$ in separate steps. Now $\{q,s\}$ is a positive parent for deriving $\{s\}$ from $\{\neg q,s\}$. Resolve $\{s\}$ with $\{r,\neg s\}$ to get $\{r\}$ and with $\{\neg r,\neg s\}$ to get $\{\neg r\}$. Resolving these units finishes the positive refutation. A step can require a positive parent and still produce a negative child.

### Why complete search will find the contradiction

Let $\operatorname{Res}^*(\mathcal K)$ contain the input clauses and all clauses derivable by repeated resolution. Only finitely many clauses are possible on finitely many variables. Repeatedly add all new resolvents until the set stops changing or reaches the empty clause. Soundness says a satisfiable input never reaches it. Completeness says every unsatisfiable input does.

To see why the search is complete, we'll eliminate one variable $p$ and show that the remaining variables carry enough information to decide satisfiability. Keep clauses containing neither sign of $p$, and collect the resolvents on $p$ between clauses with opposite signs. We can drop tautological clauses throughout. Any model of the old set satisfies the reduced set by soundness.

Now take an assignment of the remaining variables that satisfies the reduced set. Try to fill in $p$. A clause $p\lor A$ demands $p=1$ only if $A$ is false. A clause $\neg p\lor B$ demands $p=0$ only if $B$ is false. Those demands cannot occur together, because the resolvent $A\lor B$ would then be false in the reduced set. So we can give $p$ whatever value is demanded, and either value when there is no demand. The assignment extends to a model of the old set. We've eliminated one variable and preserved satisfiability in both directions.

Repeat until there are no variables left. If the input was unsatisfiable, the remaining set must be $\{\varnothing\}$, since a clause with no variables can only be the empty clause. Each clause we added has a derivation from earlier clauses, so the empty clause has a derivation from the input. A complete search that stops adding clauses without ever producing it has therefore established satisfiability.

The positive-parent restriction still gives a complete test. Suppose the set has stopped growing under positive resolution and the empty clause is absent. We can satisfy the positive clauses by making every variable true. Now choose an assignment satisfying those clauses with as few true variables as possible. Each true variable $p$ must be the only true literal of some positive clause. Otherwise we could set $p$ false and still satisfy every positive clause.

Could our assignment falsify a clause containing $\neg p$? Then $p$ is true, so resolve with the positive clause whose only true literal is $p$. The new clause is still false, because the literals we added are all false, and it has one fewer negative literal. Repeating this would produce a false positive clause, contrary to how we chose the assignment. So it satisfies every clause, including the input.

::: practice A proof certificate
Let $\mathcal K=\{\{a\},\{\neg a,b\},\{\neg b,c\},\{\neg c\}\}$. Refute it and state the pivot in each step.
::: answer
Resolve the first two clauses on $a$ to obtain $\{b\}$. With $\{\neg b,c\}$ resolve on $b$ to obtain $\{c\}$. Resolving with $\{\neg c\}$ on $c$ gives $\varnothing$. Each new unit is a forced truth on the way to the contradiction.

## 15.3 First-Order Logic, Skolemization, and Herbrand Structures

### Keep objects and claims about objects distinct

In a propositional encoding of a graph relation, we can give each possible edge its own truth value. First-order logic lets us quantify over the nodes themselves. For instance, $\forall x\exists y\,E(x,y)$ says that every node $x$ has a neighbor $y$ when $E$ is interpreted as the graph's adjacency relation. Terms stand for objects. Formulas make claims about them.

A **term** is built from variables, constants and function symbols. A function's arity is its number of arguments. If $f$ has arity two and $a$ is a constant, then $f(x,a)$ is a term. Ask whether $x$ and $f(x,a)$ are adjacent and we have the atomic **formula** $E(x,f(x,a))$. Identity, written $=$, also makes an atomic formula from two terms. Connectives and quantifiers build larger formulas from these atoms.

A variable occurrence is bound when it is in the scope of a quantifier for that variable. The nearest enclosing such quantifier binds it. Others are free. In
$$
(\exists x\,P(x))\land Q(x)
$$
the first occurrence of $x$ in a predicate is bound and the last is free. Rename the bound $x$ to a fresh variable $y$ to get $(\exists y\,P(y))\land Q(x)$. This preserves meaning. Renaming into an existing free name can capture a variable, changing what the formula says. Use a distinct fresh name for each binder when standardizing variables.

A fitting structure $\mathcal S=(\Omega_{\mathcal S},\mathcal I_{\mathcal S})$ has a nonempty universe and interprets all symbols needed by the formula. Constants and free variables select objects, an $r$-ary function symbol denotes a function $\Omega_{\mathcal S}^r\to\Omega_{\mathcal S}$, and an $r$-ary predicate denotes a relation on $\Omega_{\mathcal S}^r$. Interpret equality as equality of objects. Evaluate a term by recursively evaluating its arguments before applying the assigned function. A predicate formula is true when the resulting tuple belongs to the interpreted relation.

The truth of $\forall x\,F$ requires $F$ true under every interpretation obtained by assigning $x$ an element of the universe. For $\exists x\,F$ at least one choice suffices. Other symbols and variable values are kept fixed. A sentence has no free variables. A formula is satisfiable if it has some fitting model and valid if true in every fitting structure. In $\Omega=\{1,2\}$, let $E=\{(1,2),(2,1)\}$. Then $\forall x\exists y\,E(x,y)$ is true by choosing the other element, while $\exists y\forall x\,E(x,y)$ is false since neither column contains both edges. Swapping quantifiers of different types can change whether a witness may depend on the first choice.

### Move binders without losing their scopes

Negating $\forall x\,F$ gives $\exists x\,\neg F$, and negating $\exists x\,F$ gives $\forall x\,\neg F$. The first law asks for one counterexample to a universal statement. You may move matching quantifiers across conjunction for $\forall$, and across disjunction for $\exists$. The other pairings are not generally equivalences because witnesses can differ. For example $\exists x(P(x)\land Q(x))$ entails $(\exists xP(x))\land(\exists xQ(x))$, but the converse fails with $P=\{1\}$, $Q=\{2\}$ on $\{1,2\}$. Two universally quantified variables commute with each other, as do two existentially quantified ones.

A formula is in **prenex normal form** when all quantifiers form a prefix and the remaining matrix $F^*$ is quantifier-free. Standardize the bound variables and rewrite other binary connectives using $\land,\lor,\neg$. Move negations inward past quantifiers, switching $\forall$ and $\exists$, and pull the quantifiers to the front. Each binder may cross a conjunction or disjunction if its variable is not free in the other operand. That condition keeps the binder from claiming any new occurrences. For instance
$$
\forall x\bigl((\exists x\,P(x))\land(\exists z\,Q(x,z))\bigr)
\equiv \forall x\exists y\exists z\,(P(y)\land Q(x,z)).
$$
The $x$ inside $P$ is renamed before either existential quantifier moves. The $x$ inside $Q$ remains tied to the outer quantifier.

### Turn each existential choice into a function of earlier choices

Skolem normal form has only universal quantifiers in its prefix and no free variables. For satisfiability, first replace free variables by fresh constants. After obtaining prenex form, replace an existential variable with a fresh function of the preceding universal variables, then remove its quantifier. With no preceding universal variables the new symbol is a constant. For example,
$$
\forall x\exists y\forall z\exists w\,P(x,y,z,w)
$$
becomes
$$
\forall x\forall z\,P(x,f(x),z,g(x,z)).
$$
Read the choices in order. First we get $x$. We pick $y$ at that point, and that same $y$ must work for every $z$ that comes later. That’s why $f$ has only the first universal argument. By the time we pick $w$, we have both universal choices.

We can see both directions on the two-node graph above. If each node has a neighbor, choose one for each node and let $f$ return that choice. The interpretation of $f$ with $f(1)=2$ and $f(2)=1$ satisfies $\forall x\,E(x,f(x))$. Conversely, whenever a structure satisfies that universal formula, $f(x)$ supplies the neighbor required by $\exists y\,E(x,y)$.

For the longer prefix the same reasoning follows the quantifiers in order. For each $x$, choose a $y$ that makes the rest of the quantified formula true. Then for each pair $(x,z)$ choose $w$, using the $y$ already fixed by $x$. These choices define $f$ and $g$ in the original model. A model of the new formula gives the required witnesses back by evaluating $f$ and $g$ in order. This proves equisatisfiability.

### A universe made of ground terms

A ground term has no variables. A Herbrand universe is the set of ground terms built from the constant and function symbols in the Skolem formula. If there are no constants, introduce one fresh constant so the universe is nonempty. For a constant $a$ and one unary $f$, start at $\operatorname{Trm}_{\bot,F,0}=\{a\}$ and add one layer of function applications each time. The union $\operatorname{Trm}_{\bot,F}$ is $\{a,f(a),f(f(a)),\ldots\}$. The interpretation of the function symbol maps a term to the corresponding new term. Predicate symbols still need an interpretation, a choice of which ground tuples are true.

For a universal formula in Skolem normal form **without identity**, satisfiability is equivalent to having a Herbrand model. One direction is immediate since a Herbrand model is a model. For the other, start from any model, evaluate each ground term in it, and declare a ground predicate true when the resulting tuple belongs to the old predicate interpretation. Evaluation commutes with function application by the definition of terms. It therefore preserves the truth of each ground instance of the quantifier-free matrix, which is enough for universal quantifiers over the ground-term universe. Identity requires additional treatment: two different strings can denote the same object in another structure. If using a predicate $\mathrm{Eq}$ to encode identity, require it to be an equivalence and respect the functions and predicates, so a quotient structure can interpret true identity.

The finite Herbrand expansion $\mathcal E_{F,k}$ conjoins all instances of the matrix in which quantified variables are replaced by ground terms up to layer $k$. In $F=\forall x(P(x)\land\neg P(f(x)))$, layer $0$ substitutes $x=a$. It requires $P(a)$ and $\neg P(f(a))$, which are jointly satisfiable. Layer $1$ keeps those requirements and adds the substitution $x=f(a)$. This now requires $P(f(a))$ and $\neg P(f(f(a)))$.

Look at where $P(f(a))$ occurs. In the first instance it's the atom in the negative literal, and in the second it appears positively. It is the same ground atom in both places, so it gets one propositional variable. The two resulting units resolve to the empty clause. The contradiction was already in the first-order formula. The extra substitution made it visible to propositional resolution.

::: manim ch15_herbrand.mp4 | One more substitution exposes a contradiction
The new layer keeps the earlier clauses. Track $P(f(a))$ across both rows. The index $k$ bounds the depth of the term substituted for $x$. The fixed $f$ in the original matrix adds one further layer in the negative literal.
:::

The Herbrand expansion theorem says that a formula in Skolem normal form without identity is unsatisfiable exactly when some finite expansion is unsatisfiable. Any model of the formula would satisfy every ground instance, so a contradictory finite layer already rules a model out.

For the other direction, suppose every layer is satisfiable. We need choices that agree across the layers. The formula supplies finitely many symbols, so each finite layer uses finitely many ground atoms and has only finitely many assignments to those atoms.

Among the satisfying assignments of layer $0$, at least one extends to satisfying assignments of arbitrarily large layers. Otherwise each choice would eventually run out of extensions, leaving a large enough layer with no assignment. Choose one that keeps extending, then apply the same argument to its finitely many extensions at layer $1$. Continue one layer at a time. The compatible choices satisfy every ground instance. Give the remaining ground atoms any truth values to obtain a Herbrand model.

This gives a stopping point for a search that finds an unsatisfiable expansion. When there are infinitely many terms, finding another satisfiable layer can leave us with more layers to check. A sequence of successful finite checks need never finish.

In a first-order Horn theory, ground instances give rules on ground atoms. For example, symmetry gives $E(a,b)\to E(b,a)$ and transitivity gives $(E(a,b)\land E(b,a))\to E(a,a)$. From the fact $E(a,b)$ these rules force both derived facts. When the theory is satisfiable, the least Herbrand model makes true exactly the ground atoms forced by this closure. This is the same pattern as repeated forward steps in a graph, now with rules that can require several premises at once.

In Chapter 1, one row of a truth table was enough to find a rule that could be broken. Here one row also settles a satisfiability question when it makes every clause true. The hard case is when no row works. Now we can show why by naming the clauses that force a contradiction. In first-order logic, we can also name the substitutions that exposed those clauses. Anyone checking the argument can follow it all the way back to the original requirements.
