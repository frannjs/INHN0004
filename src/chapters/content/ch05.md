In Chapter 4 we followed arrows to find out what a relation connects. Now ask what one of those connections means. Draw an arrow from $1$ to $4$ for having the same remainder modulo $3$, and the very same test draws the arrow back. Those numbers belong in one group. Draw the arrow because $1$ divides $4$, and the reverse test fails. Here $1$ goes below $4$ in an order. We can use the shape of the arrows to tell these two jobs apart.

## 5.1 Equivalence classes tell us what a relation forgets

Take the integers and keep remainder $1$ fixed. We get $1$, we get $4$ by adding $3$, and we get $-2$ by subtracting $3$. The whole class is $1+3\mathbb Z=\{1+3z\mid z\in\mathbb Z\}$. For a positive integer $m$, we write $a\equiv_m b$ when $a,b$ have the same remainder modulo $m$. Numbers with the same remainder differ by a multiple of $m$, and adding or subtracting a multiple of $m$ preserves the remainder. So the equivalent test is $m\mid(a-b)$.

An **equivalence relation** $R$ on $A$ is reflexive, symmetric and transitive. Define $[a]_R=\{b\in A\mid aRb\}=aR$. Reflexivity puts $a$ in its own class.

Suppose we know one element $d$ that belongs to both $[a]_R$ and $[b]_R$. The arrows $aRd$ and $bRd$ both arrive at $d$. Symmetry lets us turn the second one around. Now we have a route from $a$ through $d$ to $b$, and transitivity gives $aRb$. To pick up any $x$ in $[a]_R$, go from $b$ to $a$ by symmetry, then from $a$ to $x$. The reverse argument picks up every member of $[b]_R$. So a single shared element is enough to show that the classes coincide.

The collection of classes is the **quotient** $A/R=\{[a]_R\mid a\in A\}$. Each of its members is a set of original objects. Conversely, any partition induces an equivalence by declaring two objects related exactly when they lie in the same block. This relation is transitive because the block containing the middle object is unique. So a partition and an equivalence relation are two descriptions of the same grouping.

For congruence modulo $3$, the classes are $0+3\mathbb Z$, $1+3\mathbb Z$ and $2+3\mathbb Z$. Taking $0,1,2$ supplies one representative from each class. We could use $4$ in place of $1$ and still name the same class. On a nonempty set $A$, equality gives the finest partition into singletons, and $A\times A$ gives the coarsest partition with one block. If equivalence relations $R$ and $S$ satisfy $R\subseteq S$, every $R$-class is contained in an $S$-class because every $R$-arrow is also an $S$-arrow. To stay in the class of $a$ under $R\cap S$, an object has to pass both tests, so that class is $[a]_R\cap[a]_S$.

The grouping depends on the test. Projecting $(t,x,y)$ to $(x,y)$ makes points with different $t$ equivalent when their two remaining coordinates agree. Two expressions can be equivalent as functions even if their syntax trees differ. Two programs may compute the same function while performing different numbers of operations. Say which observation is being held fixed before using “equivalent.”

::: practice Read the direction of refinement
Which inclusion holds, $\equiv_6\subseteq\equiv_3$ or $\equiv_3\subseteq\equiv_6$? Give a witness that the reverse inclusion fails.
::: answer
A multiple of $6$ is a multiple of $3$, so $\equiv_6\subseteq\equiv_3$. The pair $(0,3)$ belongs to $\equiv_3$ but not $\equiv_6$. Modulo $6$ distinguishes more pairs and therefore makes finer classes.
:::

## 5.2 Equivalence from future tests and reachability

A word read so far can be grouped by how it behaves for every possible continuation. For a language $L\subseteq\Sigma^*$, the **Myhill–Nerode relation** is defined by

$$
u\sim_L v\quad\Longleftrightarrow\quad
\forall z\in\Sigma^*\ (uz\in L\leftrightarrow vz\in L).
$$

Fix $z$. The two membership answers must agree. Equality of answers is reflexive and symmetric, and agreement through a third word is transitive. Since the reasoning holds for every $z$, this is an equivalence relation. Finding a single continuation that separates two words refutes equivalence.

Take $L$ to be the words over $\{a,b\}$ ending in $ab$. If $z$ already has length at least $2$, its last two symbols alone decide whether $uz\in L$. What remains? The empty continuation checks whether $u$ already ends in $ab$. The continuation $b$ checks whether $u$ ends in $a$. The continuation $a$ always fails. The three classes are therefore words ending in $ab$, words ending in $a$, and all remaining words, including $\varepsilon$. For example, $a$ and $ba$ are equivalent, whereas $a$ and $ab$ are separated by $z=\varepsilon$. The key was to check exactly what information about $u$ can still affect the answer.

Start with just one directed edge $a\to b$. If we're allowed to ignore the direction, the vertices belong together. If we need to get back from $b$ to $a$ along the original arrows, they belong apart. Each test extends to longer paths.

The classes of $(S\cup S^\top)^*$ are connected components when we allow both edge directions. The empty path gives reflexivity, reversing a path gives symmetry, and joining paths gives transitivity. This is the least equivalence containing $S$, since any such equivalence must contain reversed edges and all finite concatenations of those edges.

For $S^*\cap(S^\top)^*$, we need an original path each way. This too is an equivalence. If $a$ and $b$ can reach each other, and $b$ and $c$ can reach each other, join the paths in each direction to connect $a$ and $c$. It is the greatest equivalence contained in $S^*$. Any equivalence inside $S^*$ must be symmetric, so it can include a pair only if $S^*$ contains both directions.

### Proving a complete system of Myhill–Nerode representatives

When a task asks you to prove that a proposed set $R=\{r_1,\ldots,r_m\}\subseteq\Sigma^*$ is a **complete system of representatives** of $\Sigma^*/{\sim_L}$ (with no redundant representatives), verify two separate obligations:

1. **Pairwise inequivalence ($r_i\not\sim_L r_j$ for $i\ne j$).** Exhibit a **separating word** (witness) $z_{i,j}\in\Sigma^*$ for each unordered pair $\{r_i,r_j\}$ such that exactly one of $r_iz_{i,j}$ and $r_jz_{i,j}$ belongs to $L$. Because $\sim_L$ is symmetric, the upper triangle of an $m\times m$ witness table suffices.
2. **Exhaustiveness ($\forall w\in\Sigma^*\,\exists r\in R\colon w\sim_L r$).** Partition $\Sigma^*$ by the exact finite piece of information a left-to-right reader of $w$ must retain to decide $wz\in L$, and check that every word in a case agrees with its representative on all continuations $z\in\Sigma^*$.

Because $u\sim_L v$ implies $ux\sim_L vx$ for every letter $x\in\Sigma$ (restrict the universal test in $u\sim_L v$ to continuations of the form $xz'$), appending $x$ gives a well-defined transition $[u]_{\sim_L}\xrightarrow{x}[ux]_{\sim_L}$ on the quotient $\Sigma^*/{\sim_L}$—the minimal deterministic automaton of $L$. If you can exhibit an infinite sequence $u_0,u_1,u_2,\ldots$ whose pairs are all separated (for instance $a^i$ and $a^j$ separated by $b^i$ in $\{a^nb^n\mid n\in\mathbb N_0\}$), then $\Sigma^*/{\sim_L}$ is infinite.

## 5.3 Partial orders and what Hasse diagrams retain

Under divisibility on $D_{12}=\{1,2,3,4,6,12\}$, $2$ precedes $6$ because $6$ is a multiple of $2$. The pair $3,4$ is incomparable because neither divides the other. A **partial order** $R$ is reflexive, antisymmetric, and transitive. The antisymmetry condition is $R\cap R^\top=\mathrm{Id}_A$: if both orders hold then the elements are equal. A **total order** additionally requires every pair to be comparable, or $R\cup R^\top=A\times A$. The strict part $R_s=R\setminus\mathrm{Id}_A$ is transitive and asymmetric.

A Hasse diagram retains only covers. First remove all loops. Then remove any strict edge $(a,c)$ with a strict intermediate $b$ such that $aR_s bR_s c$. In Chapter 4 notation the remaining relation is $H_R=R_s\setminus R_s^2$. For divisibility, $(1,4)$ is redundant because $1\mid2$ and $2\mid4$. The edge $(3,6)$ remains because there is no divisor of $12$ strictly between them in the divisibility order.

::: manim ch05_hasse_reduction.mp4 | Keep the covers, recover the order
Watch the graph and its matrix lose the same entries. Loops are supplied by reflexivity. Longer comparisons are recovered by following the retained edges upward.
:::

For a finite poset, $H_R^*=R$. Each cover is already in $R$, so reflexivity and transitivity give $H_R^*\subseteq R$. In the other direction, take a strict pair and a longest increasing chain between its endpoints. Such a chain exists because the set is finite. Consecutive entries must be covers, since any intervening element would extend it. The chain is therefore an $H_R$ path. Draw each cover from lower to higher. An edge crossing in the drawing introduces no element or comparison. Height alone does not tell whether one vertex precedes another.

The three word orders ask where a smaller word can appear: $u\preceq_p v$ means $v=uw$, $u\preceq_s v$ means $v=wu$, and $u\preceq_i v$ means $v=wuw'$ for some words $w,w'$. Each is reflexive by using empty pieces, transitive by concatenating pieces, and antisymmetric because a proper inclusion strictly increases length. The subterm order similarly uses reachability from a subterm to the term that contains it. Its cover edges reveal direct construction dependencies when a term admits no intermediate subterm between their endpoints.

Go back to the longest chain in the proof. Finiteness guaranteed that we could keep inserting intermediate elements only so many times. The natural numbers under $\le$ still allow us to read off the order from covers because each successor covers its predecessor and a finite chain connects comparable numbers. Under $\le$ on $\mathbb Q$, any $a<b$ has $(a+b)/2$ strictly in between. There are no covers at all, so the diagram of covers loses every strict comparison.

In the divisor order on $D_{12}$, find a cover path witnessing $2\mid12$. Does $4$ lie below $6$ because their nodes are drawn at the same height?
::: answer
Both $2\to4\to12$ and $2\to6\to12$ are cover paths. There is no ascending path from $4$ to $6$, nor from $6$ to $4$. The drawing height gives a layout, and the paths give the order.

## 5.4 Ranking, linear extension, and mutually dependent elements

Suppose we need to evaluate a term. Each proper subterm needed for a computation must be handled earlier. A **linear extension** chooses a total order that respects all the original comparisons. For a finite order we can repeatedly choose a minimal remaining element, list it, and remove it. There is always a minimal element in a nonempty finite poset: following strictly smaller elements must stop. If an earlier constraint $aR_sb$ held, $b$ could not be chosen while $a$ still remained. This is the reason the procedure is a topological sort.

There is a related **ranking** that permits ties. Put $r(b)=0$ for a vertex with no incoming cover and otherwise $r(b)=1+\max\{r(a)\mid aH_Rb\}$. Thus $r(b)$ is the length of a longest cover path ending at $b$. Every cover increases the rank, so every strict comparison increases it by the path argument. To compute it recursively, start at maximal vertices and request the ranks of all their cover predecessors, remembering calculations already made. Every vertex is below some maximal vertex in a finite poset, so this visits the entire set. The strict comparison of ranks is a **strict weak order** because incomparability is exactly equality of ranks. To obtain a linear extension, order equal-rank vertices arbitrarily, then assign distinct positions in the resulting list. Every original comparison still goes forward because its two ranks were already strictly ordered.

Forward dependencies with cycles still define the reflexive, transitive quasiorder $R^*$. Let $S=R^*\cap(R^*)^\top$. Elements in the same $S$-class reach one another. Order the classes by $[a]_S\,T\,[b]_S$ when $aR^*b$. Can this test change if we pick other representatives? Start at $a'$ in the first class, go to $a$, follow the path to $b$, and finish at $b'$ in the second class. Given a path from $a'$ to $b'$ instead, we can go from $a$ to $a'$ and from $b'$ to $b$. Either pair of representatives gives the same comparison. Reflexivity and transitivity carry over from $R^*$, and if two classes compare both ways, mutual reachability puts their representatives in the same class. The quotient is a partial order. In the finite case, we can sort these classes with the same procedure used above.

For words over an ordered alphabet, lexicographic order extends the prefix order. First check for a prefix. If neither word is a prefix of the other, the first differing symbol decides. The added comparisons settle earlier ties without reversing a prefix comparison. This is a different way of choosing a linear extension when the objects have an ordered representation.

### Hasse edges and $k$-step jumps in lexicographic order

On the infinite set $\{a,b\}^*$ with $a<_{\mathrm{lex}}b$, any cross-branch pair $uav<_{\mathrm{lex}}ubw$ admits the strict intermediate word $uava$, since $uav\prec_p uava<_{\mathrm{lex}}ubw$. Thus $(uav,ubw)$ drops out of $H_{\le_{\mathrm{lex}}}$, leaving only the prefix covers $(u,ua)$ and $(u,ub)$, so $H_{\le_{\mathrm{lex}}}^*\ne{\le_{\mathrm{lex}}}$.

On a **finite** total order—such as $\{a,b\}^{\le n}$ or the permutations $\mathcal S_n$ in one-line notation ordered lexicographically—$H_R^*=R$, and $H_R$ simply steps from each element to its immediate lexicographic successor. To compute $\hat h H^k$, the permutation $k$ steps after the minimum $\hat h=(1,2,\ldots,n)$ in $\mathcal S_n$, avoid listing all $k$ predecessors. Fixing the first entry leaves $(n-1)!$ lexicographically ordered completions of the remaining $n-1$ symbols; fixing the second leaves $(n-2)!$, and so on. Write $k$ in **factorial-base** form
$$
k=d_{n-1}(n-1)!+d_{n-2}(n-2)!+\cdots+d_1\cdot 1!+d_0\cdot 0!\qquad(0\le d_m\le m),
$$
by repeatedly taking quotient and remainder modulo $(n-1)!,(n-2)!,\ldots,1!$. At each stage, $d_m$ is the $0$-based index of the next symbol to pick from the sorted list of unused elements. For example, in $\mathcal S_4$ from $(1,2,3,4)$, jumping $k=9=1\cdot 3!+1\cdot 2!+1\cdot 1!+0\cdot 0!$ picks index $1$ from $(1,2,3,4)\mapsto 2$, index $1$ from $(1,3,4)\mapsto 3$, index $1$ from $(1,4)\mapsto 4$, and index $0$ from $(1)\mapsto 1$, landing at $(2,3,4,1)$.

## 5.5 Bounds, extreme elements, and lattices

Start with $X=\{4,6\}\subseteq D_{12}$. Try to pick a maximum from $X$. If we pick $4$, then $6$ would have to divide it. If we pick $6$, then $4$ would have to divide it. Both tests fail. The same two comparisons rule out a minimum.

Now look in all of $D_{12}$. The number $12$ is above both $4$ and $6$, and it is their only common upper bound there. The common lower bounds are $1,2$. The larger in the divisibility order is $2$, since $1$ divides $2$. We found a least upper bound and a greatest lower bound by looking in the ambient order, where candidates outside $X$ are allowed.

- An **upper bound** of $X$ is $u\in A$ with $xRu$ for every $x\in X$. A lower bound $l$ satisfies $lRx$ for every $x\in X$.
- The **supremum** $\sup X$ is the least of the upper bounds. The **infimum** $\inf X$ is the greatest of the lower bounds.
- A **maximal** element of $X$ has no strictly greater element within $X$. A **maximum** is a greatest element of $X$, so it compares above every member. The minimal and minimum notions reverse the arrows.
- If $\sup X$ exists and belongs to $X$, it equals $\max X$. The corresponding rule holds for $\inf X$ and $\min X$.

Go up from each element of $X$ and keep the points every starting element can reach. Those points are exactly the upper bounds. We still have to test whether one is **least**. If two of these points are incomparable and each is minimal among the candidates, a least candidate would have to lie below both. Minimality would force it to equal both, which is impossible. For an infimum, run the same search downward and seek a greatest candidate. When $X$ is empty, every point of $A$ passes both tests because there is no member of $X$ to compare it with. Consequently $\sup\varnothing=\min A$ and $\inf\varnothing=\max A$ when those extrema exist.

A **lattice** is a poset in which every pair has a supremum and infimum. A complete lattice has both bounds for every subset, including the empty set. In $(2^A,\subseteq)$, union and intersection are the pair bounds because any set containing $B$ and $C$ must contain $B\cup C$, and any set included in both is included in $B\cap C$. Arbitrary union and intersection have the same roles within $2^A$, with $\inf\varnothing=A$ in this order. Its bounds use the ambient power set and do not require defining the unqualified set intersection of an empty family.

In a total order, the two members of any pair are comparable, so the smaller is their infimum and the larger their supremum. A total order need not be complete: $\mathbb Z$ has no upper bound for $\mathbb Z$. In a lattice, pair bounds suffice for finite nonempty subsets. For a finite $X$, first take the infimum of all but one member, then take its infimum with the last member. A lower bound of the full set must be below both objects in this last pair, and anything below both is a lower bound of the full set. This is what makes the iterative method correct. The dual argument gives suprema.

The pair operations are called **meet**, $a\sqcap b=\inf\{a,b\}$, and **join**, $a\sqcup b=\sup\{a,b\}$. They obey absorption. To see $a\sqcap(a\sqcup b)=a$, observe that $a$ is below $a\sqcup b$. We are taking the infimum of a comparable pair and already know its smaller member. Distributivity needs a separate argument in a given lattice. For example, in the order with a bottom, three incomparable middle elements, and a top, the join of two distinct middle elements is top and their meet is bottom. For three distinct middle elements $a,b,c$, the left-hand side of $a\sqcap(b\sqcup c)=(a\sqcap b)\sqcup(a\sqcap c)$ is $a$ and the right-hand side is bottom.

Under divisibility on $D_n$, pair infima and suprema are greatest common divisors and least common multiples. In the prime-exponent picture, divisibility compares the exponent of each prime. Coordinatewise minima give the greatest possible common divisor, and coordinatewise maxima give the least possible common multiple. For $4=2^2$ and $6=2\cdot3$ this produces $2$ and $12$. Chapter 12 establishes the arithmetic results behind this description.

In $D_{30}$ each prime appears at most once, so a divisor can be represented by its subset of $\{2,3,5\}$. For example, $6$ represents $\{2,3\}$ and $15$ represents $\{3,5\}$. Divisibility means inclusion of prime subsets. Their intersection $\{3\}$ represents the greatest common divisor $3$, and their union $\{2,3,5\}$ represents the least common multiple $30$. Repeating a prime changes the diagram. In $D_{12}$, the divisors $2$ and $4$ have the same prime subset, so we need the full exponent to distinguish them.

A **meet-semilattice** guarantees a meet for every pair, and a **join-semilattice** guarantees a join for every pair. In the prefix order the longest common prefix contains every other common prefix as a prefix, so this order is a meet-semilattice. The words $ab$ and $ba$ meet at $\varepsilon$ and have no common upper bound because an extension cannot begin with both. Now change the order to infix containment. The same two words have incomparable lower bounds $a$ and $b$, with no common infix containing both. The infix order therefore fails to be a meet-semilattice.

When every nonempty subset has a minimal element, the least-counterexample method extends to the partial order. Suppose there is a failure of $P$ and take a minimal member of the failure set. Every strictly smaller element satisfies $P$. Show that this forces $P$ at the supposed failure. This is **well-founded induction**. The failure set needs a minimal member here. It does not need one member below every other failure.
