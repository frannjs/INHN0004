We used bijections to rearrange a set of labels. Now give the map two different sets and see if it pairs them off perfectly. For finite sets we could just count each one. The pairing gives us a test we can still use when the lists never end.

## 7.1 Comparing Cardinalities and Function Spaces

Write $1,2,3,\ldots$ on one line and $2,4,6,\ldots$ underneath. Pair each $n$ with $2n$. Check the pairing from the second line too. Halving any positive even number takes us back to exactly one entry on the first line, so both lines are covered. This is what we mean by *the same size*. Inclusion compares membership. A bijection compares how many places there are to fill.

Write $|A|\le |B|$ if there is an injection $A\to B$, and $|A|=|B|$ if there is a bijection. Strict inequality means that an injection exists but there is no bijection. For finite sets, $|A|=n$ means a bijection with $[n]$, with $[0]=\varnothing$. An inclusion $A\subseteq B$ gives the injection $a\mapsto a$. Composition gives transitivity, since a collision in the composite of two injections would force a collision in one of its factors.

**Cantor–Schröder–Bernstein.** Two injections, one in each direction, are enough to prove equal cardinality. The theorem guarantees a bijection, and §7.4 shows how to build it. Keep the conclusion about the sets separate from what we know about either map. For example, $n\mapsto n+1$ is an injection from $\mathbb N$ to itself, and it leaves 1 unused.

**What is one element of a function space?** An element of $A^B$ is one function $B\to A$. For $A=\{0,1\}$ and $B=\{a,b,c\}$, a function is one row of three entries, each independently chosen from $\{0,1\}$. Thus $|A^B|=2^3=8$. There is one function with empty domain, including from $\varnothing$ to $\varnothing$. There are no functions from a nonempty domain to $\varnothing$.

With $F:C\times B\to A$, fix $c$ and look across its row. The row itself is the function $b\mapsto F(c,b)$. Grouping rows gives a function $C\to A^B$, and reading row $c$ at column $b$ recovers $F(c,b)$. This reversible operation is **currying**.

$$
A^{C\times B}\longleftrightarrow (A^B)^C.
$$

Compare that with $A^{(B^C)}$. Its input is a whole function $C\to B$. If all three sets have size two, a two-by-two table for the first space has four cells, while the second space has a table with four possible input functions as rows and two choices per row. Both happen to give $2^4$ here. Change $|C|$ to three. The first gives $2^6$ and the second gives $2^8$. Equality at one small parameter value never establishes an identity.

::: practice Which side is larger?
Take $|A|=2$, $|B|=1$ and $|C|=3$. Compare $|A^{(B^C)}|$ and $|A^{C\times B}|$.
::: answer
There is exactly one map from $C$ to the one-element set $B$. Therefore the first quantity is $2^1=2$. There are three pairs in $C\times B$, so the second is $2^3=8$. Compare this with the preceding example, where the direction of the strict inequality is reversed.
:::

## 7.2 Countability, Pairing, and Diagonalization

A set is **countable** when it injects into $\mathbb N$. Finite sets and the empty set count as countable. For a nonempty set, we can also ask for an enumeration, a surjection from $\mathbb N$ onto the set. Repetition is allowed. Why does this agree with the injection definition? Given an injection, read its inverse on the natural numbers it hits and fill every skipped position with one fixed element. Given an enumeration, send each element to its **first** position. Two distinct elements cannot first appear at the same position. If an injection has infinite image, list that image in increasing order and invert it to get a bijection with $\mathbb N$.

For $\mathbb Z$, the list $0,-1,1,-2,2,\ldots$ shows how to visit both directions. The position of $z$ is $2z+1$ for $z\ge 0$, and $-2z$ for $z<0$. The two branches fill the odd and even positions, respectively. For $\mathbb Q$, each fraction with positive denominator needs two entries, a numerator from this list and a denominator from $\mathbb N$. The next construction tells us how to visit every such pair.

**How can a list reach every pair?** Listing an entire row first would get stuck in that row. Instead, finish one finite diagonal before starting the next. Start with $(1,1)$, then $(2,1),(1,2)$, then $(3,1),(2,2),(1,3)$. On the diagonal $n+m=s$, the earlier diagonals contain $1+2+\cdots+(s-2)$ pairs. Position $m$ within the current diagonal gives the pairing function

$$
(n,m)\longmapsto m+\frac{(m+n-1)(m+n-2)}{2}.
$$

Each diagonal fills one consecutive interval of positions. Their intervals are adjacent and unbounded, so the formula is a bijection. Iterating it handles any fixed number of coordinates. To enumerate finite tuples of arbitrary lengths, enumerate pairs of the length and the position in its length-specific list. To enumerate finite binary words, list by length, then within each length. Every word eventually gets its turn.

::: manim ch07_pairing.mp4 | Walk the diagonals
Watch the diagonal $n+m=4$. It starts at $(3,1)$, and the two earlier diagonals have already used three slots. That's why $(3,1)$ gets index 4. Each diagonal finishes after finitely many pairs, so the list can move on.
:::

Now finish the rational enumeration. Replace the numerator by its position in the integer list and use the denominator as the second coordinate of the pair. Reading $1/2$ and later $2/4$ merely repeats the same rational. Taking its first occurrence gives the injection into $\mathbb N$. In the other direction every positive integer is a rational, so $|\mathbb Q|=|\mathbb N|$.

Can a list cover **all** infinite binary sequences? A subset of $\mathbb N$ gives one such sequence by recording a 1 at each position that belongs to it. Suppose $f:\mathbb N\to 2^{\mathbb N}$ were surjective and write the sequence for $f(i)$ in row $i$. Define a new row whose $i$th bit is the opposite of the bit in column $i$ of row $i$. Which row could it equal? Row 1 fails at column 1, row 2 at column 2, and every other row fails at its own column.

::: manim ch07_diagonal.mp4 | A bit that defeats each row
Pause before a highlighted diagonal bit is flipped. The new bit has one job: rule out that row. The finished prefix illustrates the rule for arbitrarily many rows.
:::

For any set $A$, this is **Cantor’s theorem**. The singleton map gives $|A|\le |2^A|$. If $f:A\to 2^A$, the set $D=\{a\in A\mid a\notin f(a)\}$ is a subset of $A$. Were $D=f(d)$, we would have $d\in D$ exactly when $d\notin D$. Therefore no such $f$ is surjective, and $|A|<|2^A|$. A small table reveals the mechanism, while the definition of $D$ deals with every row at once.

**From bits to real numbers.** Read $(b_i)_{i\in\mathbb N}$ as $\sum_{i\ge1}b_i2^{-i}$. Every number in $[0,1]$ has a binary expansion. Choose one expansion per number, taking the terminating expansion when possible and $1=(.111\ldots)_2$. Different numbers must give different sequences, since evaluating the sequence recovers the original number.

For the reverse injection, look at what happens to the first digit in $(.1000\ldots)_2=(.0111\ldots)_2=1/2$. All the later ones exactly make up for the missing first one. Try the same digits in base three. The first difference at position $k$ is worth $3^{-k}$, and all later differences together can cancel at most $\sum_{j>k}3^{-j}=3^{-k}/2$. The first difference survives, giving an injection into $[0,1]$. Using digits $0,2$ doubles both sides of that comparison and gives the Cantor set, the points remaining after repeated removal of open middle thirds. Finally $x\mapsto e^x/(1+e^x)$ pairs $\mathbb R$ with $(0,1)$, and inclusions plus the two-injection theorem give $|[0,1]|=|\mathbb R|$. Thus

$$
|\mathbb N|=|\{0,1\}^{*}|<|2^{\mathbb N}|=|\{0,1\}^{\omega}|=|\mathbb R|.
$$

For arithmetic with infinite cardinalities, keep translating back to functions. Adding 1 to each bit encodes binary sequences as positive-natural sequences, which are also real sequences. In the other direction, encode each real in a real sequence as one binary sequence using the bijection above. Currying makes that family one binary function on $\mathbb N\times\mathbb N$. Reindexing its inputs with the pairing function makes it one binary sequence. The two injections give $|\mathbb N^{\mathbb N}|=|\mathbb R^{\mathbb N}|=|\mathbb R|$.

Similarly $|\mathbb N\times\mathbb R|=|\mathbb R|$. To inject a pair into the binary sequences, put the natural number's binary encoding at odd positions and the real number's encoding at even positions. Both inputs can be recovered. For the reverse injection, fix the first coordinate at 1. For functions with domain $\mathbb R$, encode each output as a binary sequence. Read bit $n$ of the output at $x$ as the bit at input $(n,x)$. That is the same currying step as before, with $\mathbb R$ in place of one of the copies of $\mathbb N$. It gives $|2^{\mathbb R}|\le|\mathbb N^{\mathbb R}|\le|\mathbb R^{\mathbb R}|=|\{0,1\}^{\mathbb N\times\mathbb R}|=|2^{\mathbb R}|$. Both middle sizes therefore equal $|2^{\mathbb R}|$.

Every subset of $\mathbb N$ is countable because its elements are natural numbers. The collection of those subsets is uncountable by Cantor's theorem. Now count programs. Each program is one finite word, so the programs that produce an enumeration can account for at most countably many subsets. Some countable sets therefore have no program that enumerates them.

::: practice Encode a repeating block
What is $(.010010010\ldots)_2$? Explain why a repeating block makes the answer rational.
::: answer
The first nonzero digit is at position 2 and the same contribution recurs three positions later, multiplied by $2^{-3}$ each time. Thus the value is $(1/4)/(1-1/8)=2/7$. The geometric ratio comes from the length of the block, not from the number of ones in it.
:::

## 7.3 Finite Counting and Inclusion–Exclusion

A counting argument starts by saying what one object is. An equivalence relation on $[4]$ is uniquely specified by the partition into its classes. We can classify such partitions by block sizes before thinking about any formula.

| Block sizes | Choice that determines the partition | Count |
| --- | --- | --- |
| $4$ | All four together | $1$ |
| $3+1$ | Choose the singleton | $4$ |
| $2+2$ | Choose the partner of 1, then the rest stay together | $3$ |
| $2+1+1$ | Choose the pair | $6$ |
| $1+1+1+1$ | Each element alone | $1$ |

So the total is $15$. Why did we mention element 1 in the $2+2$ row? Choosing an arbitrary pair counts each partition twice, once for each block. Using the pair containing 1 removes the duplication. For a function $f:[4]\to[4]$, grouping inputs with equal outputs yields one such partition, and every partition can be produced by giving its blocks distinct output labels. The $4^4$ possible functions therefore determine only $15$ different equivalence relations.

**Pigeonhole principle.** If $f:A\to B$ for finite sets and $|B|>0$, some fibre contains at least $\lceil |A|/|B|\rceil$ elements. The fibres, including empty ones, account for every input exactly once. If all were smaller, their total would be less than $|A|$. Here $\lceil x\rceil$ is the least integer at least $x$. A walk of length at least $n$ in an $n$-vertex graph has at least $n+1$ vertex occurrences, so some vertex repeats. The part between two equal occurrences can be removed while preserving the endpoints.

**Inclusion–exclusion.** To count a union, add each set, subtract pairwise overlaps and add triple overlaps. For three sets, check one element in all three. It contributes $3-3+1=1$. An element in exactly two contributes $2-1=1$, and an element in exactly one contributes $1$. The same bookkeeping for any number of finite sets gives

$$
\left|\bigcup_{i=1}^{n}A_i\right|
=\sum_{\varnothing\ne I\subseteq[n]}(-1)^{|I|-1}\left|\bigcap_{i\in I}A_i\right|.
$$

For two sets, adding their sizes counts the intersection twice, so subtracting it once gives the formula. To extend to $n+1$ sets, write the union as $A_{n+1}\cup U$ with $U=\bigcup_{i=1}^n A_i$. The two-set formula gives $|A_{n+1}|+|U|-|A_{n+1}\cap U|$. The middle term accounts for all old intersections. To see what the subtraction does, apply the induction hypothesis to the union of the sets $A_{n+1}\cap A_i$. Each intersection there adds $A_{n+1}$ to an old intersection, and the minus sign outside flips its sign. That handles every intersection containing $A_{n+1}$ except the singleton choice, already counted by $|A_{n+1}|$.

::: manim ch07_overlaps.mp4 | Count a shared point once
Track the same point as the single sets, pair overlaps and triple overlap are counted. The target is a contribution of one per point in the union.
:::

**Worked example.** Among $0,\ldots,60$, how many numbers are divisible by neither 4 nor 6? Start with 61 candidates and remove the union of the two forbidden sets. There are $1+\lfloor60/4\rfloor=16$ multiples of 4, $11$ of 6 and $6$ of $\operatorname{lcm}(4,6)=12$. Common multiples are multiples of 12. The count is $61-16-11+6=40$. Each set of multiples includes zero. That is why its size has a $+1$.

Euler’s function $\varphi(n)$ counts the remainders in $0,\ldots,n-1$ relatively prime to $n$, meaning their greatest common divisor with $n$ is 1. A remainder fails this test exactly when it shares a prime divisor with $n$. A product $d$ of a subset of those primes divides $n$, so there are exactly $n/d$ multiples of $d$ in the interval. The following product expands into the same terms and signs as inclusion–exclusion.

$$
\varphi(n)=n\prod_{p\mid n,\ p\text{ prime}}\left(1-\frac1p\right).
$$

For $n=30$, start with 30 remainders and multiply by $(1-1/2)(1-1/3)(1-1/5)$ to get eight. The interval has 30 entries because it runs from 0 to 29. The previous example included its upper endpoint. Write the interval first so that every term of the count uses the same universe.

::: practice A three-way overlap
How many integers in $0,\ldots,35$ are divisible by none of $2,3,5$?
::: answer
The single-set counts are $18,12,8$; the pair counts for $6,10,15$ are $6,4,3$; and the triple count for $30$ is $2$. The answer is $36-18-12-8+6+4+3-2=9$. Zero belongs to the forbidden union once, since its contribution is $3-3+1$.
:::

## 7.4 Two Injections, Fixed Points, and Matchings

The two-injection theorem relies on a choice between using $f:A\to B$ and reversing $g:B\to A$. At $a\in A_0=A\setminus g(B)$, reversal is impossible, so use $f$. Once $a$ uses $f$, the element $g(f(a))$ must also use $f$ or its reversed image would collide with $f(a)$. Close $A_0$ under this rule:

$$
A_1=\bigcup_{k\in\mathbb N_0}(g\circ f)^k(A_0),\qquad B_1=f(A_1).
$$

The set of $g$-images in $A_1$ is exactly $(g\circ f)(A_1)$, since $A_0$ has no $g$-images. By injectivity this means $g^{-1}(A_1)=B_1$ as a preimage. Therefore $f$ bijects $A_1$ with $B_1$ and reversing $g$ bijects $A\setminus A_1$ with $B\setminus B_1$. The two maps combine with disjoint domains and disjoint images.

**Banach decomposition** works even when $f$ and $g$ are arbitrary functions. Try a candidate set $X$ for the part of $A$ assigned to $f$. That reserves $f(X)$ in $B$, leaving $B\setminus f(X)$ for $g$ to send back to $A$. For the split to fit, the part missed by those returning images must be exactly $X$. So we look for a fixed point of $F(X)=A\setminus g(B\setminus f(X))$ on $2^A$. Both images preserve inclusion and both complements reverse it. Thus $F$ is monotone.

The **Knaster–Tarski theorem** gives the least fixed point of a monotone self-map on a complete lattice as the infimum $\mu F$ of the elements $X$ with $F(X)\le X$. For our sets, start by collecting all $X$ that contain $F(X)$ and take their intersection. These two inequalities explain why the intersection actually equals its image.

Fix one of those $X$. Since $\mu F\le X$, monotonicity gives $F(\mu F)\le F(X)\le X$. So $F(\mu F)$ is below every $X$ in the set, which puts it below $\mu F$. We have one inequality.

For the other one, test $F(\mu F)$ itself for membership in that set. Applying $F$ to the inequality we just proved gives $F(F(\mu F))\le F(\mu F)$. That's exactly the membership test. Since $\mu F$ is below every member, $\mu F\le F(\mu F)$ as well.

In the power-set lattice this infimum is intersection. Taking $A_1=\mu F$ and $B_1=f(A_1)$ gives $g(B\setminus B_1)=A\setminus A_1$. This guarantees two surjections on the corresponding pieces. When $f$ and $g$ are both injective, the restrictions are bijections and we combine them as above.

**Hall’s marriage theorem.** For finite sets and allowed pairs $E\subseteq A\times B$, a matching covering $A$ is an injective function $m:A\to B$ with $m\subseteq E$. Write $XE$ for all neighbours in $B$ reached by at least one member of $X$. A matching exists exactly when $|XE|\ge |X|$ for every $X\subseteq A$. Two vertices might each have a neighbour and still have only the same one available. Test their two-element set together and the shortage becomes visible.

To see sufficiency, take a partial matching of largest size. Suppose some left vertex remains unmatched. Start from all unmatched left vertices, follow allowed edges towards the right, then matched edges back to the left, and repeat. Let $C$ be the reachable left vertices. If every vertex of $CE$ is matched, its distinct matched partner lies in $C$ and cannot be one of the unmatched starting points. This implies $|CE|<|C|$, violating the condition. Thus an unmatched right vertex is reachable. Use a shortest such alternating path. Its internal right vertices are matched to the following left vertices, and the shortest path does not repeat a vertex. Replace every matched edge along it with the intervening allowed edges. Each internal endpoint remains matched once and both previously unmatched endpoints now acquire matches. That increases the matching size, a contradiction. For necessity, the images of $X$ under an injective matching already give $|X|$ distinct members of $XE$.
