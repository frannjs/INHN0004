In Chapter 1, the truth-table row told us whether a statement holds. Here each object gives us a row of its own. Say we want the objects in $A$ or $B$. Take one candidate $x$, ask whether it belongs to $A$ and whether it belongs to $B$, and take the “or” of those answers. The objects that pass are the union. Keep this way of reading a set expression as the expressions get longer.

## 2.1 An object, a collection, and a membership question

What does a set remember? It remembers which objects belong to it. It does not remember the order in which we named them or how many times each was named. Thus $\{2,1,2\}=\{1,2\}$ and has cardinality $2$. We can determine equality by checking membership in both directions.

Write $x\in A$ if the object $x$ is an element of $A$. Write $A\subseteq B$ if every element of $A$ belongs to $B$. The left-hand sides have different roles: $x$ is one object in the first statement, while all members of $A$ are being tested in the second. For $B=\{1,\{2\}\}$, $\{2\}\in B$ is true but $\{2\}\subseteq B$ is false because $2\notin B$. The empty set $\varnothing$ is a subset of every set because it has no element that can violate the inclusion. It need not be an element of a given set. In particular, $|\varnothing|=0$ while $|\{\varnothing\}|=1$.

The notation $A\subsetneq B$ says $A\subseteq B$ and $A\ne B$. Once $A\subseteq B$ is known, to establish strictness look for one element of $B\setminus A$. To refute the original inclusion look in the opposite direction, for one element of $A\setminus B$.

A **finite** set can be enumerated by a finite list. Its cardinality $|A|$ counts only distinct elements. We write $\mathbb N_0=\{0,1,2,\ldots\}$, $\mathbb N=\{1,2,\ldots\}$ and $[n]=\{1,\ldots,n\}$, with $[0]=\varnothing$. The familiar number sets $\mathbb Z$, $\mathbb Q$, $\mathbb R$ and $\mathbb C$ contain the integers, rationals, reals and complex numbers respectively. Comparing the sizes of infinite sets needs the function-based method later in the book.

## 2.2 Define a set by selection or by replacement

Start with $A=\{0,1,2,3,4\}$. If we ask for the even elements of $A$, we test each existing object and keep those satisfying the predicate. This is **separation** or **selection**:

$$
\{x\in A\mid x\text{ is even}\}=\{0,2,4\}.
$$

If we ask to double each element of $A$, we produce objects that need not belong to $A$. This is **replacement**:

$$
\{2x\mid x\in A\}=\{0,2,4,6,8\}.
$$

Work backwards from the proposed output. Can we put $8$ into the replacement set? We need an input in $A$ whose double is $8$, and $4$ does it. Try $7$ and there is no such input. The same output may have several witnesses. In $\{x^2\mid x\in\{-2,-1,0,1,2\}\}$ both $-2$ and $2$ produce $4$, which enters the set once.

The starting set is essential. If we allow unrestricted comprehension, $T=\{x\mid x\notin x\}$ appears to be a set. Now test $T\in T$. It would hold exactly if $T\notin T$, which is impossible. Russell's paradox pinpoints why the course starts selection and replacement from an already defined set. A universe $\Omega$ is a chosen set for the question, not a set of all sets.

::: practice Keep or transform?
Let $A=[5]$. Compute $\{a\in A\mid 2a\in A\}$ and $\{2a\mid a\in A,\ 2a\in A\}$.
::: answer
The condition $2a\in[5]$ holds for inputs $1,2$. The first set keeps those inputs and is $\{1,2\}$. The second keeps the doubled outputs and is $\{2,4\}$.
:::

## 2.3 Set operations are tests on one element

Take $A=\{a,b,c\}$ and $B=\{b,c,d\}$. Fix a candidate $x$. Asking if it belongs to both sets is the conjunction $(x\in A)\land(x\in B)$. That test defines their intersection. A similar translation works for each basic operation.

| Set | Membership condition on $x$ | Value in this example |
| --- | --- | --- |
| $A\cup B$ | In $A$ or in $B$ | $\{a,b,c,d\}$ |
| $A\cap B$ | In $A$ and in $B$ | $\{b,c\}$ |
| $A\setminus B$ | In $A$ and outside $B$ | $\{a\}$ |
| $A\mathbin\Delta B$ | In exactly one of the two | $\{a,d\}$ |
| $\overline A=\Omega\setminus A$ | In $\Omega$ and outside $A$ | $\{d\}$ if $\Omega=\{a,b,c,d\}$ |

A Venn diagram and a Karnaugh–Veitch (KV) map lay out the same membership cases. Fix $x\in\Omega$. The bits $10$ say that $x$ is inside $A$ and outside $B$, whether we draw that region as part of a circle or as a grid cell. Symmetric difference selects exactly $10$ and $01$. The case $00$ still belongs to $\Omega$. It consists of the points outside both sets.

::: manim ch02_venn_kv.mp4 | From a Venn region to a membership cell
Each highlighted region and cell describes the same pair of answers to $x\in A$ and $x\in B$. The symmetric difference keeps the two cases with exactly one positive answer.
:::

With three sets, use the $B$ bit for the rows and the $(A,C)$ bits for the columns. This column order keeps the $A$ region in the middle two columns and the $C$ region in the right two columns. Neighboring columns differ in one bit, including across the two ends.

| $B$ bit | $(A,C)=00$ | $(A,C)=10$ | $(A,C)=11$ | $(A,C)=01$ |
| --- | --- | --- | --- | --- |
| $0$ | | | ✓ | |
| $1$ | | ✓ | ✓ | |

The marked cells give $A\cap(B\cup C)$. In the $B=0$ row, we need both $A=1$ and $C=1$, so only $11$ is marked. In the $B=1$ row, the union condition already holds, so mark both columns with $A=1$. Comparing expressions means comparing selected cells within the same universe. A particular arrangement of sets may leave some cases empty. Keep all possible combinations when checking an identity that must hold for arbitrary sets.

Take $x\in\Omega$ and look at $\overline{A\cup B}=\overline A\cap\overline B$. On the left, we first keep the cases $10$, $01$, and $11$ in the union. Complementing leaves $00$. On the right, $\overline A$ requires the first bit to be $0$ and $\overline B$ requires the second bit to be $0$. Their intersection is the very same $00$ cell. This is De Morgan's law. The companion law is $\overline{A\cap B}=\overline A\cup\overline B$: everything except $11$ has at least one zero. We can use the same tests to prove the two inclusions directly, one in each direction. To refute an alleged identity, realize one differing row with an object that passes one test and fails the other.

Distributivity follows from the same translation. In $A\cap(B\cup C)$, $x$ must be in $A$ and must pass at least one of the tests for $B,C$. That can happen through $A\cap B$ or through $A\cap C$. Thus the set equals $(A\cap B)\cup(A\cap C)$. The dual identity interchanges union and intersection. The basic rules also include commutativity, associativity for either operation by itself, idempotence, absorption, and complements. For instance $A\cup(A\cap B)=A$ because everything added by $A\cap B$ was already in $A$. Difference does not share commutativity: here $A\setminus B=\{a\}$ and $B\setminus A=\{d\}$.

::: practice One membership row
Is $A\setminus(B\cap C)=(A\setminus B)\cap(A\setminus C)$ an identity?
::: answer
No. Take $x$ in $A$ and $B$ but outside $C$. It passes the left test and fails the right test. The correct connective on the right is union, because missing the intersection means missing at least one of its two factors.
:::

## 2.4 Power sets, set families, and partitions

$2^A$, also written $\mathcal P(A)$, is the set of all subsets of $A$. For $A=\{1,2\}$, $2^A=\{\varnothing,\{1\},\{2\},\{1,2\}\}$.

Let's make that list without trying to remember it. Decide about $1$ first. If we leave it out, the choice about $2$ gives $\varnothing$ or $\{2\}$. If we put it in, that same choice gives $\{1\}$ or $\{1,2\}$. Either way, there are two ways to finish. Each element of a finite set gives one independent yes-or-no decision, so $|2^A|=2^{|A|}$. At the empty set there are no decisions to make, and one completed subset. That is why $2^{\varnothing}=\{\varnothing\}$.

A family gathers sets to which we apply a common operation. For a nonempty family $\mathcal M$, $x\in\bigcup\mathcal M$ means at least one member of the family contains $x$, and $x\in\bigcap\mathcal M$ means every member contains $x$. Try $\mathcal M=\{\{1,2\},\{2,3\},\{2,4\}\}$. For the union we pick up every new element and finish with $\{1,2,3,4\}$. For the intersection, start with $1$ and $2$ from the first set. We lose $1$ at the second set and carry $2$ all the way through, so the intersection is $\{2\}$. The course defines $\bigcup\varnothing=\varnothing$ and leaves $\bigcap\varnothing$ undefined. When all sets under discussion lie in a fixed universe, the empty intersection relative to that universe can be taken to be the universe itself.

Now look for whole sets $X$ contained in every $M\in\mathcal M$. What can go into $X$? Every element we put there has to survive all the membership tests, so it has to come from $\bigcap\mathcal M$. Any selection from that intersection already passes every test. Find the common elements first, then take their power set $2^{\bigcap\mathcal M}$. In our example the solutions are $\varnothing$ and $\{2\}$.

A **partition** of $A$ is a family of nonempty subsets whose union is $A$ and whose distinct members are disjoint. Each $a\in A$ belongs to exactly one block. For $\{1,2,3\}$ the partition $\{\{1,3\},\{2\}\}$ is valid. The overlapping family $\{\{1,2\},\{2,3\}\}$ covers the same set but fails because $2$ appears in both blocks. The even and odd integers partition $\mathbb Z$ in the same way, with the remainder deciding membership. In Chapter 5 we will recover the blocks directly from a relation.

## 2.5 Tuples and product grids

A sequence has positions. For example, $(1,2,1)$ differs from $(1,1,2)$ even though both contain the same elements. Write $(a_i)_{i\in I}$ for a sequence indexed by $I$ when the order of positions is understood. A finite sequence is a tuple. Two $k$-tuples agree exactly when their corresponding entries agree.

In a Cartesian product $A\times B$, a candidate is an ordered pair $(a,b)$ and both coordinate conditions must hold: $a\in A$ and $b\in B$. A row for each $a$ and a column for each $b$ produce $|A||B|$ cells when the sets are finite. Distinct cells are distinct pairs. Swapping the coordinates is a bijection onto $B\times A$, but the sets themselves can differ. With $A=\{1,2\}$ and $B=\{a,b,c\}$, $(1,a)$ belongs to $A\times B$ alone.

For $A,B\subseteq\Omega$, dividing each coordinate into inside and outside gives four disjoint blocks of $\Omega\times\Omega$. Only the inside-inside block belongs to $A\times B$. Therefore

$$
(\Omega\times\Omega)\setminus(A\times B)
=(A\times\overline B)\cup(\overline A\times B)\cup(\overline A\times\overline B).
$$

A single failed test puts the pair in the complement. That's why we kept the two mixed blocks as well. The same coordinate test proves distribution over union, intersection, and difference in either factor. For instance, on the right side of $A\times(B\setminus C)=(A\times B)\setminus(A\times C)$, start with a pair in $A\times B$. The first coordinate is already in $A$, so the only way to fail membership in $A\times C$ is for the second coordinate to be outside $C$.

For three coordinates, $(a,b,c)$, $((a,b),c)$, and $(a,(b,c))$ are differently structured objects. A flattening gives a natural correspondence, but the nested products are not literally equal. We use $A^k$ for $k$ positions from $A$ and $A^0=\{()\}$ because there is one empty tuple. If a factor is empty, its Cartesian product with any other set is empty.

In $[4]^2$, take $A=\{1,2\}$ and $B=\{2,3,4\}$. What is the size of the complement of $A\times B$, and why is it larger than $\overline A\times\overline B$?
::: answer
There are $16$ cells in the universe and $6$ in the product, so the complement has size $10$. Only $2\cdot1=2$ cells fail both tests. The remaining eight fail exactly one.
:::

## 2.6 Words and the tree of finite decisions

When symbols from an alphabet $\Sigma$ can be recovered unambiguously, we can write a tuple of symbols as a word. Over $\{a,b\}$, the word $aba$ recovers $(a,b,a)$. If $ba$ were itself a third symbol with the same printing, the same text would admit $(a,ba)$ as well. The need for a unique reading explains why a suitable alphabet or encoding matters.

Write $\Sigma^k$ for the words of length $k$. The empty word $\varepsilon$ represents the empty tuple, so $\Sigma^0=\{\varepsilon\}$. In the binary tree for $\Sigma=\{a,b\}$, each edge appends one symbol. The node $ab$ is one level below $a$ and one level above $aba$. Each word has a unique path from the root because deleting its last symbol gives its unique parent. The whole collection is $\Sigma^*=\bigcup_{k\in\mathbb N_0}\Sigma^k$. A **language** is any subset $L\subseteq\Sigma^*$.

::: manim ch02_word_tree.mp4 | Read a word as a path
Track the node labels with each choice of edge. A horizontal level fixes the number of decisions, and following one branch from the root fixes their order.
:::

Concatenation $uv$ places the symbols of $v$ after those of $u$. Thus $a\,ba=aba$, whereas $ba\,a=baa$. The operation is associative because both bracketings give the same ordered list of symbols. We have $u\varepsilon=\varepsilon u=u$ and $|uv|=|u|+|v|$. For languages $L,L'$, $LL'=\{uv\mid u\in L,\ v\in L'\}$. For instance $\{a,ab\}\{\varepsilon,b\}=\{a,ab,abb\}$. Two pairs produce $ab$, which is counted once. This is a small example of why the product rule for pairs need not count distinct concatenations.

::: practice A word versus a set of words
Explain the difference between $\varepsilon$, $\{\varepsilon\}$, and $\varnothing$. What happens when an arbitrary language $L$ is concatenated with each of the last two?
::: answer
$\varepsilon$ is the one word of length zero. $\{\varepsilon\}$ is a language with one member, and $\varnothing$ is a language with no members. $L\{\varepsilon\}=L$ because each word can be followed by the empty word. $L\varnothing=\varnothing$ because there is no second word to choose.
:::
